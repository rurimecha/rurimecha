# 只读 WebDAV 播放

服务提供 `/dav/`（`/dav` 同样可用），用于通用播放器浏览目录、读取字幕等文件及原文件播放。只支持 OPTIONS、PROPFIND、GET、HEAD；写入、删除、改名、移动、复制和锁定方法返回 405，Allow 为 `OPTIONS, PROPFIND, GET, HEAD`。不提供完整可写 DAV。此协议独立于 `/api/v1`，OpenAPI 的 `x-webdav` 指向本文。

## 账户密码直连

播放器填写现有账户的当前用户名和密码，使用 HTTP Basic 认证。启用 HTTPS 后，服务地址为 `https://证书对应的服务器名称:HTTPS端口/dav/`；仅使用 HTTP 时为 `http://服务器:HTTP端口/dav/`。HTTP 会明文传输密码，请只在可信网络中使用。强制 HTTPS 模式保留 HTTP 监听并返回 307；WebDAV 客户端应直接使用 HTTPS 地址，不依赖客户端跟随重定向。无需先网页登录或创建 DAV 会话，不提供独立 DAV 密码、会话签发或令牌配置步骤。网页 Cookie 和 API Bearer 仍用于原有管理接口，不用于 DAV。

DAV只验证账户身份并提供只读文件访问，不签发网页/API令牌。密码验证与网页登录共用账户凭据；目录路径不包含用户名。管理员可管理 admin/member 账户；各账户共享只读媒体来源目录，账户管理与个人资料隔离见 accounts.md。

修改用户名或密码后播放器须更新配置；旧凭据的新请求立即失败，已开始的长响应每分钟复查并在失效时取消。退出或撤销网页/API会话不撤销仍然有效的账号密码。DAV不创建持久会话，也不占256个网页登录会话额度。

密码验证与登录共用每分钟 20 次尝试及最多 2 个并行验证的预算。错误凭据返回 401，超出预算返回 429；成功验证后的正常目录和 Range 读取不反复消耗登录预算，账号修改和停用仍即时生效。

账号停用、产品授权失效和远程访问限制同时适用于 WebDAV。未激活或授权失效时，只有内置管理员可以使用 WebDAV。参见 [账号](accounts.md) 与 [网络设置](network.md)。

## 虚拟目录

`/dav/` 直接列出已添加、可用的媒体来源根，例如 `/dav/同人音声/`、`/dav/ASMR/`，下面保持索引中的实际文件夹与文件。没有 `sources`、`works`、`playlists` 中间分类，也不再按作品、播放组、扩展名创建重复虚拟层。

kikoeru 兼容来源也显示为根目录，已入库作品按 RJ 号平铺。文件读取优先使用已完整保存到服务器的副本，否则通过服务器从来源读取；播放器仍使用同一 DAV 路径。来源断线时，未保存的文件读取失败，已完整保存的文件仍可读取。DAV 不启动保存任务。

根目录使用来源的配置名称；同名根追加完整来源ID区分，并避让与其他根名称的冲突。更改来源名可能改变其DAV路径。根内目录/文件名使用原始名称；非法UTF-8、XML禁止字符或保留前缀仍映射为可逆的 `~b~` 加Base64URL形式，保留可用扩展名。URL路径段需百分号编码，XML href正确转义。

所有已索引普通文件都可列出和读取，包括音视频、同目录字幕、图片、文本和压缩包。空来源与已索引空目录也保留；无来源时DAV根为空目录。来源视图独立于作品归纳，未归档或排除的已索引可用文件仍可出现。非音视频作为附件提供。目录是索引的只读投影，不复制、改名、挂载或建立媒体软链接；移除来源后文件打开仍即时检查可用性。

多个客户端可以同时浏览目录和读取文件，各连接独立处理读取位置和取消。目录查询仅包含当前路径和需要的直接子项，不因全库超过 250000 条目而拒绝其他目录或单文件读取。单个目录最多列出 250000 个直接子项，单次 XML 响应最多 64 MiB；超限明确返回 507 `directory_too_large`，不会成功返回截断目录。超大目录本身的 Depth 0 查询和目录内单文件读取仍可使用。

目录元数据按来源配置及已发布索引版本复用；每次请求在一致的只读快照中检查版本，后续请求可见扫描已发布的变化，正在处理的请求保持自己的快照。实际文件读取始终复查节点与来源，旧投影不能恢复已移除文件的访问。索引不完整时仅展示已知节点，不进行实时目录扫描、不推断删除。

## 浏览与读取

PROPFIND 支持 Depth 0/1、空请求体、allprop、propname 和指定属性；响应为 207 XML，含当前资源，Depth 1 再含直接子项。支持 resourcetype、displayname、getcontentlength、getcontenttype、getlastmodified、getetag；未知属性以属性级 404 返回。supportedlock 为空。不支持无限递归：Depth infinity 或省略 Depth 返回 403 和 DAV `propfind-finite-depth`；非法 Depth 或 XML 为 400，请求体上限 64 KiB。目录列表无 500 项分页截断。

GET/HEAD 对普通媒体提供原始字节，支持单段、多段、后缀 Range、206/416、条件请求、Content-Length、Content-Range、Last-Modified 和弱 ETag。HEAD 不返回正文。索引元数据未知时查询实际文件大小，不能将未知冒充零。文件发生变化后属性可能暂旧，GET/HEAD 的实际状态为准。目录 GET/HEAD 为 405。转码、外置字幕、播放历史同步均不包含在 DAV 中。

错误使用对应 HTTP 状态；PROPFIND 属性状态为 XML，其他请求可能返回公共 JSON 错误结构或 HTTP 错误文本。未认证为 401，带 `WWW-Authenticate: Basic realm="rurimecha", charset="UTF-8"`。所有入口禁止查询参数。代理需透传 DAV 方法、Authorization、Depth 和 Range，避免媒体压缩或缓冲造成字节范围变化。
