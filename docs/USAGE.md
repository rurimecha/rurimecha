# 使用说明

首版提供 Linux x86-64、Docker x86-64 和 Windows x64 服务器包。选择对应平台的包，按下载页提供的 SHA-256 校验后解压。Android 客户端单独安装。

- **Linux** 在解压目录运行 `./rurimecha-core -data-dir ./data`。
- **Windows** 在解压目录用 PowerShell 运行 `.\rurimecha-core.exe -data-dir .\data`。
- **Docker** 解压 Compose 包，在该目录的 `.env` 中填写 `RURI_IMAGE` 为下载页给出的镜像，填写 `RURI_MEDIA_DIR` 为宿主机媒体目录，运行 `docker compose up -d`。在 Ruri 中添加 `/media/library`。媒体目录默认只读，应用资料保存在独立的 `ruri-data` 卷。

在服务器上打开 `http://127.0.0.1:8080/`。首次用户名为 `admin`。Linux 和 Windows 的初始密码在数据目录的 `api-token` 文件中。Docker 在 Compose 目录运行 `docker compose exec core cat /data/api-token` 查看初始密码。登录后可在账号设置中修改密码。

## 重置内置管理员密码

在自己的终端操作，脚本会显示用户名和新密码。请使用同一套安装包附带的脚本。

- **Linux** 先停止 Ruri，从解压目录运行 `./reset-admin-password.sh`。如果使用了其他数据目录，在命令后加上该目录的路径。成功后重新启动 Ruri。
- **Windows** 先关闭 Ruri，双击解压目录的 `reset-admin-password.cmd`。如果使用了其他数据目录，在 PowerShell 中运行 `.\reset-admin-password.cmd "D:\RuriData"`，将示例路径换成实际目录。成功后重新启动 Ruri。
- **Docker** 在使用发行版 Compose 文件的目录运行 `./reset-admin-password.sh`。如果 Ruri 正在运行，脚本会暂时停止它，重置后重新启动。

使用脚本显示的用户名和新密码登录。用户名和资料会保留，已用该账号登录的设备需要重新登录。

## 网络设置

初次启动使用 HTTP 端口 8080。Linux 和 Windows 可从局域网访问。Docker 示例默认只允许宿主机访问；要从局域网访问，可调整 Compose 的端口映射。在管理员的账号菜单打开“网络设置”，可选择 IPv4、IPv6、监听地址及端口。保存端口或地址会中断连接，请用页面中显示的新地址重新连接。新地址启用失败时会恢复原配置。

“局域网范围”留空时自动识别直连私有网段。需要指定范围时，每行填写一个网段，例如 `192.168.1.0/24` 或 `fd00::/64`。从局域网外访问时，先开启服务器的“允许远程访问”，再到“用户管理 → 访问权限”允许相应账号远程访问。HTTP 会明文传输登录和媒体数据，请使用可信网络或 VPN。

## 导入媒体

添加媒体路径时，分别选择“自动扫描”“自动归档”“自动刮削”“自动提取媒体信息”。之后可在目录浏览的“目录操作 → 自动处理”中分别调整。关闭一项不会改变其他项目。

自动扫描关闭后，可以手动扫描；已开启的归档、刮削和媒体信息提取会使用已有结果。没有可处理内容时等待，不会为此自动扫描。归档需要完整的目录记录；刮削需要已有且带有效商品编号的作品；媒体信息提取需要已发现的音视频文件，无需先归档。

移除根目录只清除库内记录，媒体文件保留。数据目录放本机磁盘，媒体可以放在挂载目录。

## 搜索作品

在搜索框输入标题、声优、社团或作品编号。只知道编号开头时，可以输入 `RJ12` 这类部分编号，编号以它开头的作品会优先显示。只记得标题时，在「搜索范围」选择「仅标题」，可以用作品已保存的任一语言标题搜索。

输入至少两个字符并稍等，搜索框会显示作品候选。同一编号有多个本地副本时，可以根据候选里的来源和目录打开对应副本。按回车或点「搜索」查看完整结果。

## 换机时恢复资料

1. 在旧服务器用管理员账号打开「迁移与恢复」。只搬作品资料时，选择「全部作品资料」。要把账号、偏好、收藏、收听进度和服务器设置也搬过去，选择「系统数据和全部作品资料」。系统数据也可单独导出。含系统数据的包需要设置密码，请保存好迁移包和密码。
2. 把媒体硬盘接到新设备，或把媒体目录复制到新设备。安装 Ruri 后先用管理员账号登录，再到「迁移与恢复」选择迁移包。填写媒体在新服务器上的目录，然后点「预览恢复」。
3. 检查缺失文件，再点「恢复」。缺失的文件仍可保留资料、收藏和进度。把文件放回原来的相对位置并重新扫描，即可恢复播放。恢复了系统数据时，请重启 Ruri，并使用迁移前的账号和密码登录。

只搬一部作品时，在作品详情选择「迁移此作品」导出。两台设备上作品在媒体来源中的相对位置相同时，可从目标作品详情的同一入口恢复，替换该作品的资料和人工整理结果。新设备没有对应作品时，也可从「迁移与恢复」导入单部包。

迁移包保留刮削来源、原有资料、人工编辑和图片。之后仍按原有设置更新资料。音视频原文件、日志、任务记录、设备授权和手机本机下载请分别处理。

## 复制界面文本

电脑上可拖动选择标题、说明、作品资料、路径和错误提示等文字，再按 Ctrl+C（macOS 为 Command+C）复制；手机上可长按文字后选择复制。按钮和操作菜单保持点击使用，不参与文本选择。输入框仍按原有方式编辑和复制。

## 选择资料来源

在“刮削设置”中开启“获取作品资料”，支持 DLsite 音声编号（RJ）。可分别开启缓存站和 DLsite，用箭头调整先后顺序。先尝试排在前面的来源，未取得资料时再试下一个已开启来源。已有资料需要更新时，在作品的“分项刷新”中选择重新获取。

使用缓存站时填写其首页地址，并在缓存站“访问密钥”页面创建“按编号查询”密钥。将密钥填入设置，先点击对应的“测试连接”，看到成功后再保存。密钥只在创建时显示，请自行保存；登录密码不能代替密钥。

## 资料语言

首次安装默认查找简体中文和日文资料。可在“刮削设置”中调整要查找的语言，至少保留一种。作品有哪些语言版本取决于资料来源。

在作品详情的“查看资料”中选择已保存的语言，标题、介绍、制作人员、标签、系列、价格、图片和其他商品资料会一起切换；缺少的字段显示未提供。编辑商品资料时先选择语言，保存后只保护该语言的修改。商品编号和原始资料语言由各版本共用。

如果资料显示为「未知」，打开「编辑作品资料」，切到「未知」并点击「设置未知资料的语言」。这会同时归类标题、介绍和商品资料。目标语言已有资料时，「合并」只补缺少的字段，「覆盖」用未知资料替换整份目标版本。归类后的资料可像刮削资料一样刷新和恢复。

需要单独更新某一种语言时，在作品的“分项刷新 → 强制刷新商品资料”中选择“本次获取的语言”，再开始下载。它不会改变全局语言开关；已保存的其他语言继续保留。任务页可查看各语言结果，“重试失败项”只重试未完成的语言。

## 分项刷新

作品菜单可分别更新商品资料、补齐图片、重新下载图片、获取音视频信息、扫描文件和重新归档。只更新资料不会下载图片；需要图片时单独选择补图。重取媒体信息可能较慢，通常先使用补齐选项即可。

## 缓存站

运行 `ruri-scrape -listen 127.0.0.1:8091 -data-dir ./scrape-data`，浏览器打开对应地址。首次用户名 admin，密码在该目录 initial-password 文件中。

在缓存站设置中，同样可以分别开启四种资料语言，并选择默认优先返回简体中文或日文。查询已明确指定语言时，优先使用该次选择。作品资料页可切换语言或重新获取单种语言；下载资料包会保留已保存的全部语言。来源未说明资料语言时，资料显示为「未知」。

当前缓存站只保存文字资料，不下载图片，也不提供手工编辑。可以按编号查询、重新获取、删除及导入导出。自动采集只需设置“最多保存作品数”和“每天最多新增作品数”，0表示关闭自动采集；例如100会尽量成功新增100部，已有作品和获取失败不占数量。容量满后会腾出较早更新资料的位置。

## 手机与播放

Android 安装包打开后，选择“搜索局域网服务器”或手动填写服务器地址。选中搜索结果后，确认地址并点击连接，再登录。搜索不到时，请检查手机和服务器是否连接到同一局域网，以及服务器是否开启了自动发现。

普通音频可直接播放。需要转码、音量标准化或读取内嵌字幕时，请在服务器安装 FFmpeg 和 FFprobe。Windows x64 可将两个工具所在目录加入 `PATH`，或在启动时用 `-ffmpeg-path` 和 `-ffprobe-path` 分别指定完整路径。请选择支持 `fd` 输入协议的版本。

视频播放时打开「全屏播放」。播放中约 3 秒无操作会收起控制栏。Android 轻点画面显示或隐藏控件，双击画面左侧或右侧可前后跳 10 秒。网页可移动鼠标或按键唤出控件，空格暂停或继续，方向键前后跳，Esc 退出全屏。

拖动进度条时查看目标时间和可用的画面预览，松手跳转。在「播放选项」中可切换字幕、音轨或跳到可用章节。音轨和章节取决于文件已提取的媒体信息，画面预览和切换到指定音轨需要服务器安装 FFmpeg。

服务器授权生效后，管理员可在“用户管理”创建账号。在账号的“访问权限”中可停用或重新启用账号。停用后该用户会退出登录，也无法连接 WebDAV。普通用户共享媒体库，收藏集、播放列表、偏好、收听进度和珍藏片段各自保存。密码或角色改变后需重新登录。

如果启动提示数据目录不兼容，请选择新的空目录；需要保留原有数据时不要删除旧目录。更多客户端接入说明见 [开发者 API 文档](api/README.md)。

## 珍藏片段

服务器授权生效后，在「正在播放」或视频全屏的「播放选项」中选择「珍藏片段」。进度条会出现两个手柄，拖动它们选择起点和终点。默认选中当前位置之后的 30 秒，靠近末尾时会选中最后 30 秒。可点「放大选区」细调，再点「查看全曲」回到完整进度条。

点击「试听选段」核对范围，试听到终点会自动停止。点击「保存片段」或「取消」后会回到选段前的播放位置。提示无法确定时长时，请先为该文件获取媒体信息。试听和播放已保存的片段需要服务器安装 FFmpeg。

从账号菜单打开「珍藏片段」，点击条目播放。也可从「片段操作」加入队列、播放列表和收藏集，或编辑范围和删除。列表可以同时放完整音视频和多个珍藏片段。播放片段时，进度条与台本采用片段内时间。片段沿用原作品封面，范围以外的内容可通过原文件播放。

删除片段会同时移除保存列表中的相关条目，原媒体保留。源文件暂时不可用时，片段会显示不可用。服务器授权失效后，已保存片段会保留。可以从片段页查看服务器授权，恢复授权后继续使用。

## 官方安卓播放授权

未激活或授权到期时，仅内置管理员可以登录，使用网页播放和 WebDAV。在“服务器授权”填写许可证密钥和服务器名称，选择“激活服务器”，即可创建其他用户并使用官方 Android 客户端播放。授权恢复后，其他用户需要重新登录。

激活、续期更新和反激活需要服务器联网；日常使用可在授权有效期内离线，手机播放仍需连接服务器。到期后请续期，并使用原密钥更新授权。增加或调整授权所覆盖的功能，一般无需重新激活或绑定。

更换服务器前选择“反激活”，成功后在新服务器激活。若网络失败，请重试反激活；原服务器无法启动时，请联系许可证提供者核对购买信息后释放绑定；当前尚未开放邮箱登录和用户自助远程解绑。已离线的旧服务器可能继续使用到原授权到期。

替换 Docker 容器前请保留应用数据卷和已配置的宿主机标识。换机时请按上文迁移资料，并在新服务器重新激活。

当前授权中心：[Ruri 授权中心](https://ruri-license.rurimecha-11c899c9.workers.dev)。授权中心不依赖用户本机持续在线，日常播放仍连接自己的 Core。

## 查看同一作品的不同版本

作品库会把已确认关联的商品版本放在同一个入口中，卡片显示商品版本数和服务器收录数。没有编号的作品仍独立显示。

在详情中点击“查看其他商品版本”后：

1. 在“选择服务器副本”中选择本次要操作的服务器收录。相同编号的不同目录都会保留，可以根据来源和完整目录位置区分。
2. 点击“服务器播放”播放该份收录；点击“打开服务器文件”查看文件；管理员对应的入口为“打开服务器文件与编辑资料”，还可编辑该版本的资料。
3. 在“商品版本”和“资料语言”中选择要阅读的资料。切换这里不会切换正在播放的文件；商品版本语言也不等于音频语言。

标为“仅有商品资料”的版本尚未在服务器收录，不能从服务器播放。价格、评分和销量属于正在查看的商品，不会与其他版本混用。从卡片加入收藏集或播放列表时，如有多个服务器副本，会先要求选择操作对象。

“服务器已收录”只说明服务器保存了文件，不代表 Android 已下载。要查看手机中的下载，请打开“本机版本”或“本机媒体库”。

普通作品详情的“更多操作 → 查看全部版本”也可以打开版本入口。关联资料获取失败时，已取得的资料和服务器文件会保留，可在任务详情查看结果并重试。单次获取有数量和范围上限，已取得的缓存可供再次获取时复用。

## 隐私模式与播放记录

点击主界面或播放器上的眼睛按钮，开启或关闭「隐私模式」。应用会记住当前设备的选择。

开启后，作品封面、图片和视频画面显示默认图；作品标题、作者、标签、简介、文件名、字幕及相关输入内容按字符数量显示为星号。导航、播放按钮、时间和进度仍可使用。点击某处遮罩上的小眼睛可查看该处内容 3 秒，再次点击立即遮回；切换页面、曲目或离开应用也会结束查看。输入框仍可编辑，保存的内容保持原文。

Android 在隐私模式下通过设备扬声器开始播放前会询问，选择「继续播放」后才开始；一次确认持续到音频设备连接状态变化。耳机或蓝牙设备断开时暂停，重新连接不会自动播放。从通知或媒体按键播放时，如需确认，请打开应用。片段试听同样适用。正在外放时开启隐私模式，会先暂停并询问。通知和锁屏也使用遮蔽后的文字与默认图。网页支持内容遮蔽，外放确认由 Android 应用提供。

隐私模式仍会保存收听进度。从账号菜单打开「收听记录」，可删除单条记录，或点击「清空播放记录」。删除会同时清除已保存的续播位置和完成状态，收藏、播放列表、珍藏片段及媒体文件保留，其他账号的记录不受影响。删除正在播放的记录不会中断播放，但本次播放不再保存该项进度；重新选择内容播放后继续记录。

## Android 本机媒体库

在作品详情选择播放版本和格式，再点击「下载到本机」，勾选要保存的文件。文件菜单也可以下载单个音视频。默认仅使用 Wi-Fi 或有线网络；关闭此限制后可能使用移动数据。一次最多下载 500 个文件，本机媒体库最多保存 500 个下载版本。

下载需要登录且服务器授权有效。应用保存原文件、已有多语言作品文字、封面和可取得的文本字幕，不下载商品样图、介绍插图或无关附件。原文件能否离线播放取决于设备支持的格式；不支持时请选择服务器中的其他格式重新下载。

在连接页、登录页或账号菜单打开「本机媒体库」，可查看进度、暂停、继续、取消和删除下载。取消任务保留已完成文件。媒体与附加资料分别显示结果，封面或字幕未完成时可以重试补齐。空间不足时先删除不需要的本机内容，再继续。

下载完成后，即使退出登录、服务器无法连接或授权过期，也可以从本机媒体库浏览和播放。在线作品详情的「本机版本」同样可以选择已下载内容；「服务器播放」继续使用服务器。本机播放不会自动联网补播，也不会向服务端同步本机队列、收藏、最近收听或进度。

本机播放器支持后台播放、通知控制、循环、随机、睡眠定时、字幕台本和视频全屏。服务器队列与本机队列分别保存，切换来源时只有一处播放，恢复队列时先暂停。隐私模式和外放确认同样适用于本机播放。

「刷新作品资料」只更新文字、封面和字幕，不重新下载完整媒体，也不自动增加服务器新增曲目；该操作需要连接原服务器、登录原账号并具有有效授权。本机媒体库暂不支持下载珍藏片段、迁移本机资料或选择外部存储目录。

清理浏览缓存、退出登录或更换服务器会保留下载。删除本机版本只影响本机内容，服务器文件保留；卸载应用或清除应用数据会删除全部下载和本机记录。

## 优先打开的商品版本

首页和作品库会直接打开优先版本的详情，卡片上的播放按钮播放同一个服务器副本。打开账号菜单的「外观与浏览偏好」，可选择「按版本语言偏好」或「原作优先」，并调整商品版本的语言顺序。未设置顺序时优先已收录原作；优先版本暂不可播放时选择其他可用副本。

商品版本语言决定优先打开日文版、中文版等哪一份商品；「元数据语言偏好」只决定标题、介绍和标签的显示语言。例如，可以优先播放日文原版，同时阅读中文介绍。

在作品详情点击「设为优先版本」，可为当前账号单独指定这部作品的默认副本；「恢复跟随全局偏好」取消指定。点击「查看其他商品版本」阅读其他版本的资料；同一商品有多个目录时，可使用「切换服务器副本」。查看资料不会自动改动优先项或正在播放的内容。

直接打开具体作品、文件或播放历史时保持该目标。搜索完整商品编号时优先展示该商品；仅有商品资料时可查看资料，不能自动播放另一商品的文件。Android 的本机版本仍由用户明确选择，不与服务器版本偏好或个人播放记录合并。
