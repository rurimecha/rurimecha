# Rurimecha の機能

Rurimecha（Ruri）は、自分の音声・ASMR・動画を整理して楽しむためのツールです。Linux x86-64、Docker x86-64、Windows x64 でサーバーを動かし、ブラウザーや別途インストールする Android アプリから接続します。

## 表示言語

- ソフトウェアと公式サイトは簡体字中国語・繁体字中国語・日本語・英語に対応し、手動またはシステムに合わせて選択できます。ログイン後の選択はアカウントに、未ログインの選択は端末に保存します。作品情報・音声・字幕の言語は別々に選びます。
- インストーラーは現在簡体字中国語、管理・CLI ツールは原則英語です。過去のリリースノートは中国語・英語で提供します。

## ライブラリの整理

- サークル・声優・イラストレーターを関連作品の表紙で表示し、ライブラリの作品を閲覧できます。DLsiteや互換ソースで関連作品を探し、手動で更新できます。
- 元のフォルダーを閲覧し、ファイルを作品に整理できます。スキャン、整理、作品情報取得、メディア情報抽出を個別に設定し、作品に含めるファイルも手動調整できます。
- kikoeru 互換ライブラリに接続し、作品の検索やサークル・タグ・声優の閲覧・絞り込み、作品の追加、必要なファイルのサーバー保存ができます。
- タイトル、声優、サークル、タグ、作品番号で探し、RJ 番号の一部から候補を表示できます。タイトルのみの検索も可能です。
- DLsite の RJ 作品情報を取得したり、タイトル・紹介・画像を編集したりできます。四言語の情報を同時に保持し、個別に表示・更新します。
- 関連する原作と言語版を一緒に閲覧し、重複コピーはフォルダーで選べます。原作や言語版を優先し、再生とは別言語で紹介を読めます。
- タイトル、パス、作品情報を選択してコピーできます。

## 再生・続きから・コレクション

- 作品やフォルダーから音声・動画を再生し、効果音あり・なし、MP3・WAV など提供される版・形式を選べます。
- 字幕・台本、スリープタイマー、再生位置の復元、コレクション・プレイリストを利用できます。管理者は台本の作成・編集・変換ができます。
- コレクションは作品カード・一覧で表示し、単体の音声・動画・クリップは音の小箱にまとめます。スマート発見も同じ形で、直接コレクションとして保存できます。
- プレイリストは曲、重複、順番を保持します。選んだ項目からリスト全体を続けて再生したり、単独・検索結果のみ・シャッフル再生や後続項目のキュー追加ができます。旧版の自作コレクションは更新時にプレイリストになります。
- 音声ページ、下部の操作、台本ウィンドウ、ローカルプレーヤーで 10 秒戻る・進むができ、一時停止中は停止を保ちます。
- 台本の表示領域を調整でき、大きな Web 画面では台本を開いたまま閲覧できます。Android はほかのアプリ上に字幕を表示できます。
- Windows はスタートメニューから開き、「Ruri → 更新を確認」から更新できます。Windows・Linux のインストール時は IP・ポートを確認でき、Windows の削除ではデータの保持・明示的な消去を選べます。元メディアは保持します。
- 有効なライセンスで好みの区間を試聴・保存し、再生や一覧への追加ができます。クリップは元ファイルを参照するため、元ファイルが必要です。
- Linux・Windows・Docker は音量正規化、互換変換、内蔵字幕用ツールを同梱します。[メディアツール](USAGE.md#メディアツールの準備)を参照してください。
- WebDAV 対応アプリから Ruri の認証情報で元ファイルを読み取り専用で再生できます。証明書、HTTP・HTTPS 別ポート、HTTPS 転送を設定できます。

## モバイルとプライバシー

- Android で LAN 検出やアドレス入力、バックグラウンド、メディアキー、全画面動画、キュー復元ができます。
- 有効化済みサーバーから元ファイル、文章、カバー、テキスト字幕を保存し、完成後はローカルライブラリでオフライン再生できます。保存・キュー・お気に入り・位置は端末に別保存します。
- プライバシーモードでカバー・動画・文章を隠し、3 秒だけ確認できます。Android は外部スピーカー再生前の確認とヘッドホン・Bluetooth 切断時の停止に対応します。
- 履歴を個別・全件削除し、対応する続きの位置も消去できます。

## 共有と端末の移行

- 組み込み管理者は Web・WebDAV を利用できます。有効なライセンスで追加アカウントを作り、共有ライブラリと個別のコレクション・設定・位置を使えます。
- LAN 範囲とユーザーごとの外部接続を設定できます。Nginx は HTTP サーバーに HTTPS 入口を提供でき、同一ホストと標準 Docker ブリッジでは信頼プロキシの入力不要です。
- 有効なセッションの端末名、種類、ログイン IP・時刻を確認し、不要なものを解除できます。
- システム情報、全作品、一作品を出力し、新しいメディアパスで復元できます。不足ファイルの情報を保持し、戻してスキャンすると再利用できます。
- ゲストの閲覧・再生を有効化できます。個人の保存はできず、無効化すると利用を終了します。

- 管理者は問題と操作結果を確認し、調査時に設定から詳細な診断を有効にできます。調査後は無効にしてください。


## 対応範囲と制限

- サーバーは Linux・Windows x64、Docker Linux x86-64 です。ARM パッケージはありません。
- 互換ソースは元ファイルを直接再生します。ローカルの変換・内蔵字幕・音量正規化は形式と利用可能なツールに依存します。
- WebDAV のアップロード・改名・削除・位置同期、リバースプロキシのサブパス入口には対応しません。
- ブラウザーは実際のホスト名を取得できません。セッション名は見分けるための表示で、端末の本人確認には使えません。

## リスニング統計とおすすめ

- サイドバーまたはアカウントメニューから「リスニングとおすすめ」を開きます。「リスニング統計」では再生時間、カレンダー、月別の推移、よく聴く作品・声優・サークル・タグを確認できます。過去30日、12か月、年、全期間を選べます。サーバーのライブラリからの再生を記録し、スマートフォンのローカルライブラリは含めません。
- 作品詳細で「自分の評価」を選び、星1～5つで評価できます。もう一度開くと変更や取り消しができます。評価はアカウントごとに作品全体へ付け、形式や再生グループで共通です。カードには公開評価と自分の評価を分けて表示します。
- 「あなたへのおすすめ」では、好みに合いそうな作品、いつもと違う作品、久しぶりに聴く作品を選べます。作品詳細を開いたり、直接再生したりできます。「おすすめを入れ替える」で候補を変更します。再生位置の記録を削除しても、統計と評価は残ります。


### 動画の画質と変換制限

動画再生中にプレーヤー設定の「動画の画質」を開きます。変換に対応する動画では解像度とビットレートを選択でき、切り替え後はバッファリングして現在位置から再開します。変換できない動画には元の形式だけを表示します。ローカルソースと読み取り可能な kikoeru 互換ソースの動画に対応します。元の形式を再生できるかは端末によります。互換再生の「自動」は既定の画質予算を使い、回線速度に応じた継続的な自動調整は行いません。

終了したタスクと実行ログは最大48時間保存されます。終了後の詳細には再試行できる未完了項目を表示し、成功項目は合計に含まれます。記録が消えた後は作品やソースから再実行できます。作品情報、お気に入り、再生位置、字幕の下書きは保持されます。今回の更新では以前のタスク記録を引き継がず、移行成功後に旧データベースのバックアップを削除します。
