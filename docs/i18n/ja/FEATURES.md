# Rurimecha の機能

Rurimecha（Ruri）は、自分の音声・ASMR・動画を整理して楽しむためのツールです。Linux x86-64、Docker x86-64、Windows x64 でサーバーを動かし、ブラウザーや別途インストールする Android アプリから接続します。

## 表示言語

- ソフトウェアと公式サイトは簡体字中国語・繁体字中国語・日本語・英語に対応し、手動またはシステムに合わせて選択できます。ログイン後の選択はアカウントに、未ログインの選択は端末に保存します。作品情報・音声・字幕の言語は別々に選びます。
- インストーラーは現在簡体字中国語、管理・CLI ツールは原則英語です。過去のリリースノートは中国語・英語で提供します。

## ライブラリの整理

- フォルダーや作品の更新メニューから、作品情報や画像の更新、メディア情報の読み取り、スキャン、整理を個別に実行できます。作品情報を更新する際は言語を選び、手動で編集した内容を保持できます。スキャンとメディア情報の読み取りはローカルソースで利用できます。専用のフォルダーがなく、複数のローカルソースにファイルがある作品では、読み取るソースを選べます。
- 同じソース内の閲覧や一時的な画面移動ではファイル種類の絞り込みを保持し、別のソースや作品では既定に戻します。条件のクリアやフィルターの保存もできます。
- 作品で「すべてのファイル」を選ぶと、全再生グループのファイルと添付ファイルを確認できます。ファイル名を選ぶと、テキストの閲覧、画像の拡大、PDF のページめくりができます。
- 元のファイルを残して作品を個別に削除できます。作品のファイルと通常のサブフォルダーは無視され、独立した子作品は残ります。設定で削除した作品や無視したフォルダーの除外を確認・解除できます。消去した情報と参照は復元されません。
- 公開声優プロフィールと出演作品を表示し、ライブラリのコピーを開くか内蔵ASMR.oneで検索できます。ライブラリ内の声優と名前管理も保持します。サークルとイラストレーターでは既存の作品閲覧・外部検索を利用できます。
- 有効なサーバーライセンスがある場合、管理者は「ネットワーク設定」の「スマート接続」を有効にして、DLsite や ASMR Online への別の経路を試せます。アクセスできるかはサーバーのネットワークと地域によって異なります。無効にしても取得済みの資料は保持されます。
- 元のフォルダーを閲覧し、ファイルを作品に整理できます。スキャン、整理、作品情報取得、メディア情報抽出を個別に設定し、作品に含めるファイルも手動調整できます。
- 削除できないASMR.oneソースを標準搭載。作品を探して追加でき、プロキシと保存先も設定できます。同じURLのユーザー追加ソースと共存し、声優画面からは標準ソースを開きます。ダウンロード先はサーバー上で選択するか直接入力でき、保存時に書き込みの可否を確認します。
- kikoeru 互換ライブラリに接続し、作品の検索やサークル・タグ・声優の閲覧・絞り込み、作品の追加、必要なファイルのサーバー保存ができます。
- 互換ソースの作品をツリーでフォルダー・ファイル・拡張子から選び、元の階層を保ってサーバーに保存できます。完成済みをスキップし、進捗確認・停止・未完了の再試行ができます。
- タイトル、声優、サークル、タグ、作品番号で探し、RJ 番号の一部から候補を表示できます。タイトルのみの検索も可能です。
- DLsite の RJ 作品情報を取得したり、タイトル・紹介・画像を編集したりできます。四言語の情報を同時に保持し、個別に表示・更新します。
- 関連する原作と言語版を一緒に閲覧し、重複コピーはフォルダーで選べます。原作や言語版を優先し、再生とは別言語で紹介を読めます。
- タイトル、パス、作品情報を選択してコピーできます。
- Kikoeru 互換ソースのアドレスと必要に応じてプロキシを入力し、保存前に「接続をテスト」を選択してください。追加済みのソースでもテストできます。成功はライブラリを閲覧できることを示し、音声のダウンロード速度を保証するものではありません。
- サーバーに保存が完了していない ASMR.one の音声では、プレーヤーで「スムーズな再生を優先」または「音質を優先」を選べます。前者は提供されている場合に小さい音声を使用し、後者は選択した元ファイルを再生します。切り替えても現在位置から続けられます。保存済みのファイルはローカルの元ファイルで再生し、ダウンロードも元ファイルを保持します。次の曲の先読みは、現在の曲の読み込みが完了してから始まります。

## AI 翻訳と整理提案

- サーバーライセンスが有効な場合、管理者は「AI 設定」でプロバイダーのモデルを追加して接続をテストし、機能ごとに使うモデルを選べます。プロバイダーごとにシステムプロキシ、直接接続、または指定したプロキシを使用できます。
- Android の端末内ライブラリでは、「AI 設定」からプロバイダーを追加し、モデルを取得して接続をテストできます。保存後は作品の詳細から翻訳を始められます。クラウドモデルの利用にはスマートフォンのインターネット接続が必要です。
- ローカルゲートウェイで累計使用量の確認、日付での検索、呼び出し詳細の保持上限の設定ができます。
- 台本、作品情報、フォルダーやファイルの表示名の翻訳と、整理提案が使えます。フォルダー内や作品に属するファイルとフォルダーの表示名をまとめて翻訳できます。翻訳先の言語と既存の翻訳名をスキップするかを選び、今回のプロンプトを調整できます。ボタンで原名と画面の言語に対応する翻訳名を切り替えられます。
- 作品情報では、まとめて翻訳する項目を選んだり、タイトルやタグなどを個別に翻訳したりできます。開始前に今回のプロンプトを確認・編集し、生成後は原文と項目ごとに比較して訳文を修正し、選んだ結果を保存できます。

## 再生・続きから・コレクション

- 作品やフォルダーから音声・動画を再生し、効果音あり・なし、MP3・WAV など提供される版・形式を選べます。
- 音声と動画は同じフォルダーの同名字幕を優先し、同じ作品・ソース内の別フォルダーの字幕も選べます。手動の選択や字幕オフは、ファイルごとにアカウントへ保存されます。
- 字幕・台本、スリープタイマー、再生位置の復元、コレクション・プレイリストを利用できます。管理者は台本の作成・編集・変換ができます。
- コレクションは作品カード・一覧で表示し、単体の音声・動画・クリップは音の小箱にまとめます。スマート発見も同じ形で、直接コレクションとして保存できます。
- プレイリストは曲、重複、順番を保持します。選んだ項目からリスト全体を続けて再生したり、単独・検索結果のみ・シャッフル再生や後続項目のキュー追加ができます。旧版の自作コレクションは更新時にプレイリストになります。
- 音声ページ、下部の操作、台本ウィンドウ、ローカルプレーヤーで 10 秒戻る・進むができ、一時停止中は停止を保ちます。
- 読み込み中やバッファリング中も一時停止できます。再生ページの作品名から詳細を開け、進行バーは現在の時間と全体の長さを読み上げます。
- 台本の表示領域を調整でき、大きな Web 画面では台本を開いたまま閲覧できます。Android は Ruri 内とほかのアプリ上に字幕を表示でき、ロック解除後も表示を続けます。字幕をタップすると閉じるボタンが現れます。
- Windows ではスタートメニューから開けます。インストール時にデスクトップショートカットも追加できます。Windows と Linux のインストール時は待ち受け IP とポートを確認できます。Windows のアンインストールではデータが標準で保持され、必要に応じて消去できます。元のメディアは保持されます。
- 「設定 → バージョンと更新」でバージョンと更新を確認できます。Android は接続画面からも確認できます。Linux と Docker はサーバーの導入方法に沿って更新します。
- 現在使っているサーバーまたは端末のライセンスを有効化すると、好みの区間を試聴・保存し、再生や一覧への追加ができます。クリップは元ファイルを参照するため、元ファイルが必要です。
- Linux・Windows・Docker は音量正規化、互換変換、内蔵字幕用ツールを同梱します。[メディアツール](USAGE.md#メディアツールの準備)を参照してください。
- WebDAV 対応アプリから Ruri の認証情報で元ファイルを読み取り専用で再生できます。証明書、HTTP・HTTPS 別ポート、HTTPS 転送を設定できます。

### 動画の画質と変換制限

動画再生中にプレーヤー設定の「動画の画質」を開きます。変換に対応する動画では解像度とビットレートを選択でき、切り替え後は読み込みが済むと現在位置から再開します。元の形式のみ表示される動画は、端末がその形式に対応していれば再生できます。ローカルソースと読み取り可能な kikoeru 互換ソースの動画に対応します。互換再生の「自動」は既定の画質を使用します。回線が遅いときは、手動で画質を下げられます。

## モバイルとプライバシー

- Android のホームから「この端末のライブラリ」と「サーバーに接続」を直接開けます。端末のフォルダーを追加し、フォルダーや作品から探して再生できます。接続できない場合は、サーバー選択画面で LAN 検出やアドレス入力ができます。バックグラウンド再生、メディアキー、全画面動画、キューの復元に対応します。
- Android のローカルライブラリではフォルダーと作品の項目別更新、メディア情報の取得、バックグラウンドタスクの確認ができます。ASMR.one や Kikoeru 互換ソースの作品から、端末に保存するファイルを選べます。
- Android のローカル再生設定では、音声トラックの測定と音量の正規化、端末が対応する形式での互換コピーの作成、埋め込みテキスト字幕全体の WebVTT 保存ができます。
- ログインしたサーバーから元ファイル、文章、カバー、テキスト字幕を保存できます。「ダウンロードタスク」で進捗を確認し、端末のライブラリの「ダウンロード済み」から以前のファイルも新しいファイルも再生できます。「ダウンロード先」で今後の保存先を選べます。すでに保存したファイルは現在の場所に残ります。
- プライバシーモードでカバー・動画・文章を隠し、3 秒だけ確認できます。Android は外部スピーカー再生前の確認とヘッドホン・Bluetooth 切断時の停止に対応します。
- 履歴を個別・全件削除し、対応する続きの位置も消去できます。

## 共有と端末の移行

- 初回設定には初期管理パスワードが必要です。Windows デスクトップでは自動入力され、ブラウザーには Windows・Linux・Docker の確認方法が表示されます。ご自身のパスワードを設定すると初期管理パスワードは無効になります。
- テスト期間中は公式サイトで自分のメールアドレスを入力すると、無料ライセンスが自動送信されます。各アドレスにつき 1 回限りで、発行後 7 日以内に有効化し、その後 31 日間利用できます。届かない場合は後で再申請するか、発行済みライセンスを確認してください。
- 有効なサーバーライセンスがあれば、管理者はユーザー管理でアカウントを作成でき、追加のアカウントでログインできます。メディアは共有し、コレクション、プレイリスト、設定、再生位置はアカウントごとに保存します。
- LAN 範囲とユーザーごとの外部接続を設定できます。Nginx は HTTP サーバーに HTTPS 入口を提供でき、同一ホストと標準 Docker ブリッジでは信頼プロキシの入力不要です。
- 有効なセッションの端末名、種類、ログイン IP・時刻を確認し、不要なものを解除できます。
- システム情報、全作品、一作品を出力し、新しいメディアパスで復元できます。不足ファイルの情報を保持し、戻してスキャンすると再利用できます。
- 有効なサーバーライセンスがあれば、ゲストの閲覧・再生を有効化できます。個人の保存はできず、無効化すると利用を終了します。
- 管理者は問題と操作結果を確認し、調査時に設定から詳細な診断を有効にできます。調査後は無効にしてください。
- 終了したタスクと実行ログは最大48時間保存されます。終了後の詳細には再試行できる未完了項目を表示し、成功項目は合計に含まれます。記録が消えた後は作品やソースから再実行できます。作品情報、お気に入り、再生位置、字幕の下書きは引き続き利用できます。

## リスニング統計とおすすめ

- サイドバーまたはアカウントメニューから「リスニングとおすすめ」を開きます。「リスニング統計」では再生時間、カレンダー、月別の推移、よく聴く作品・声優・サークル・タグを確認できます。過去30日、12か月、年、全期間を選べます。ローカルライブラリの統計は端末に保存されます。サーバーの統計は、そのサーバーに接続して確認できます。
- 作品詳細で「自分の評価」を選び、星1～5つで評価できます。もう一度開くと変更や取り消しができます。評価はアカウントごとに作品全体へ付け、形式や再生グループで共通です。カードには公開評価と自分の評価を分けて表示します。
- 「あなたへのおすすめ」では、好みに合いそうな作品、いつもと違う作品、久しぶりに聴く作品を選べます。作品詳細を開いたり、直接再生したりできます。「おすすめを入れ替える」で候補を変更します。再生位置の記録を削除しても、統計と評価は残ります。

## 対応範囲と制限

- サーバーは Linux・Windows x64、Docker Linux x86-64 です。ARM パッケージはありません。
- 互換ソースでは配信元のファイルを再生できます。選べる画質、変換、埋め込み字幕、音量正規化は、ファイルとサーバーで利用できるメディアツールによって異なります。
- WebDAV のアップロード・改名・削除・位置同期、リバースプロキシのサブパス入口には対応しません。
- ウェブからのログインは、セッション一覧にブラウザーと OS が表示されます。ログイン時刻と合わせて確認できます。
