**想先看看怎麼用？** 開啟[示範站](https://asmr.rurimecha.top/)，在登入頁選擇「訪客體驗」，即可瀏覽和播放示範作品；訪客的收藏和收聽進度不會儲存。Ruri 不提供音聲作品，請加入自己提供的媒體資料夾。

**選擇使用方式：** Windows 可使用 MSI 安裝程式，無需命令列；Linux 和 Docker 請依下文安裝。Android 需要連接已執行的 Ruri 伺服器。內建管理員無需授權即可使用網頁和 WebDAV；Android 線上播放、下載與珍藏片段需要有效伺服器授權。下載完成後可在手機上離線收聽。

## 安裝與首次登入

從發行頁下載對應的包，並按頁面上的 SHA-256 校驗。伺服器支持 Linux x86-64、Docker Linux x86-64 鏡像和 Windows x64。Android 手機安裝包需要另外下載，手機要連接一台已經運行的 Ruri。[發行下載](https://github.com/rurimecha/rurimecha/releases)

先完成下面一種安裝，再按[首次設定管理員密碼](#首次設定管理員密碼)操作。自己的電腦就是伺服器時，直接在這台電腦上打開；裝在 NAS 或另一台電腦上時，使用那台設備的局域網地址。

### Windows 安裝

1. 下載 `.msi` 安裝包並雙擊打開嚮導，點「下一步」，選擇安裝目錄。安裝包僅支持「為當前用戶安裝」，無需管理員權限；預設目錄為 `%LOCALAPPDATA%\Programs\Rurimecha`，開始菜單入口也僅對當前 Windows 用戶可見。其他 Windows 用戶需要分別安裝。若曾安裝舊版 EXE 安裝包，先在 Windows 設定中卸載舊版，再安裝 MSI；媒體庫資料會保留。
2. 設定監聽 IP 和端口，再點「下一步」檢查是否可用。首次安裝預設 IP 為 `0.0.0.0`、端口為 `8080`，表示接收這台電腦所有 IPv4 地址上的連接；只供本機使用時填 `127.0.0.1`。選擇某個 IP 時，必須填寫這台電腦實際擁有的地址。端口被佔用時，退出佔用它的程序或改用其他端口，再重試。升級或重新安裝預設沿用已有網絡設定。
3. 確認安裝，完成後從開始菜單打開 **Rurimecha**。如提示缺少 WebView2，安裝微軟的 [Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 後重新打開。
4. 在窗口頂部點「Ruri → 打開數據資料夾」，用記事本打開 `setup-code` 檔案，複製設定碼，返回 Ruri 完成首次設定。

點窗口右上角的 × 會隱藏到系統托盤，Ruri 繼續運行。雙擊托盤圖標可重新打開；需要完全關閉或安裝更新時，在托盤圖標上點右鍵，選擇「退出 Ruri」。讓其他設備訪問的方法見[連接與網絡](#連接與網絡)。應用數據儲存在 `%LOCALAPPDATA%\Rurimecha\data`，更換程序安裝目錄不會移動這些數據。

### Linux 安裝

1. 下載 Linux x86-64 伺服器包並完整解壓。在解壓目錄打開終端，運行：

   ```sh
   sudo ./install.sh
   ```

2. 在安裝提示中填寫監聽 IP 和端口，直接回車使用 `0.0.0.0` 和 `8080`。安裝會檢查地址是否可用、端口是否被佔用；檢查失敗時不會覆蓋已有網絡設定。安裝後會啓動 Ruri，並在開機後自動運行。使用預設設定時，可從另一台電腦打開 `http://服务器的局域网地址:8080/`，伺服器本身不需要圖形界面。
3. 在伺服器終端運行下列命令，複製輸出中的設定碼：

   ```sh
   sudo journalctl -u rurimecha.service -g 'Ruri administrator setup code:' -n 1 --no-pager
   ```

服務安裝需要 systemd；隨包音影片工具要求 glibc 2.35 或更新版本，例如 Ubuntu 22.04 或 Debian 12。應用資料儲存在 `/var/lib/rurimecha`。Ruri 以 `rurimecha` 用戶運行，這個用戶需要能讀取媒體資料夾及其上級目錄；不要為解決讀取問題把整塊媒體盤設為所有人可寫。

也可以直接指定安裝時的監聽地址和端口，例如：

```sh
sudo ./install.sh --listen-ip 192.168.1.20 --listen-port 18080
```

把 IP 換成這台伺服器實際擁有的地址。`0.0.0.0` 表示全部 IPv4 地址，`127.0.0.1` 表示只允許本機連接。無交互安裝時，新安裝使用預設地址和端口；已有安裝在未指定參數時保留原網絡設定。升級時也可以在提示中選擇保留已有設定。

不安裝服務也可以在解壓目錄運行 `./rurimecha-core -data-dir ./data`，並保持終端運行；設定碼會顯示在終端中。這種方式的數據在所選目錄內，升級時繼續使用同一個目錄。

### Docker 安裝

以下以已安裝 Docker 和 Docker Compose 的 Linux 電腦或 NAS 為例，使用公開倉庫提供的 `compose.yaml`。NAS 的容器管理界面也可以填寫相同的鏡像、目錄映射和端口。鏡像需要 x86-64 設備，ARM 設備不能直接使用此包。

**1. 準備檔案和媒體目錄。** 下載 [compose.yaml](https://raw.githubusercontent.com/rurimecha/rurimecha/main/packaging/docker/compose.yaml) 和 [reset-admin-password.sh](https://raw.githubusercontent.com/rurimecha/rurimecha/main/packaging/docker/reset-admin-password.sh)，放在同一資料夾。在 `compose.yaml` 旁新建一個名為 `.env` 的文本檔案，填寫：

```dotenv
RURI_IMAGE=docker.io/rurimecha/rurimecha:<版本号>
RURI_MEDIA_DIR="/srv/media/音声"
```

把 `<版本号>` 換成發行頁給出的版本，**不保留尖括號**；把第二行換成這台 Docker 主機上已經存在的媒體資料夾。想跟隨最新正式版時，可用 `RURI_IMAGE=docker.io/rurimecha/rurimecha:latest`。Windows 的 Docker Desktop 使用 Linux 容器時，媒體路徑可寫為 `D:/ASMR`，並允許 Docker 訪問該磁盤。

這個資料夾會在 Ruri 中顯示為 `/media/library`。添加媒體時選擇這個路徑，不要填寫宿主機的 `/srv/media/音声` 或 `D:/ASMR`。示例以只讀方式打開媒體；手工台本可選擇「儲存到 Ruri」，無需開放媒體寫入權限。

**2. 啓動並完成首次設定。** 在 Compose 檔案所在目錄運行：

```sh
docker compose up -d
docker compose logs core
```

在日誌中找到 `Ruri administrator setup code:` 開頭的一行，複製設定碼。在運行 Docker 的電腦上打開 `http://127.0.0.1:8080/` 完成設定。手機上的 `127.0.0.1` 指手機自己，不能用來訪問這台電腦。

**3. 讓手機或其他電腦連接。** 不需要其他設備訪問時，保留示例設定即可。需要局域網訪問時，同時完成以下兩項：

- 在 Ruri 的「網絡設定」查看並記下「當前局域網範圍」。在「局域網範圍」中保留這些原有網段，再另起一行加入家庭網絡的網段。例如設備地址為 `192.168.1.x`、子網掩碼為 `255.255.255.0` 時，填 `192.168.1.0/24`。Docker 中自動識別的網段可能不包含家庭網絡；只改端口映射仍可能被拒絕。監聽地址保持預設全部 IPv4 地址，不填容器里並不存在的宿主機 IP。
- 編輯 `compose.yaml` 中 `ports` 的一行。假設 Docker 主機的局域網地址是 `192.168.1.20`，希望從 `18080` 端口訪問，改為：

  ```yaml
  ports:
    - "192.168.1.20:18080:8080"
  ```

儲存後運行 `docker compose up -d`，手機和其他電腦用 `http://192.168.1.20:18080/` 訪問。原來的 `http://127.0.0.1:8080/` 不再是這份映射的入口。把示例 IP 換成自己設備的地址，並在主機防火牆中允許家庭網絡連接該端口。

端口映射可以這樣讀：**在哪個主機地址接收：對外端口：Ruri 內部端口**。

| Compose 中的設定 | 應使用的地址 | 適合誰 |
| --- | --- | --- |
| `127.0.0.1:8080:8080` | Docker 主機上打開 `http://127.0.0.1:8080/` | 僅本機，或由同機 Nginx 中轉 |
| `192.168.1.20:18080:8080` | `http://192.168.1.20:18080/` | 指定局域網地址上的其他設備 |
| `8080:8080` | 主機各地址的 `8080` 端口 | 會監聽全部主機地址，需自行限制訪問範圍 |

只更換對外端口時，修改中間的數字，最後的 `8080` 保持不變，也不需要改 Ruri 的內部端口。可以運行 `docker compose ps` 檢查實際映射。[Docker 端口映射說明](https://docs.docker.com/engine/network/port-publishing/)

Ruri 中顯示的 `172.x.x.x` 地址通常是容器地址，手機應填寫主機的局域網地址及對外端口。Docker 中的自動發現未必能傳到家庭網絡，搜索不到時直接填寫地址。

**4. 使用伺服器授權功能時，提供宿主機標識。** 若需要 Android 在線播放、多人帳號或珍藏片段，還需讓容器讀取這台主機的標識。在 Linux 主機上，確認 `/etc/machine-id` 檔案存在且非空，再在 `compose.yaml` 的現有 `volumes` 列表下增加一行：

```yaml
volumes:
  - ruri-data:/data
  - ${RURI_MEDIA_DIR}:/media/library:ro
  - /etc/machine-id:/run/ruri-host/machine-id:ro
```

這是服務 `core` 下的目錄列表，保留檔案末尾原有的 `volumes: ruri-data:` 定義。不要複製另一台機器的標識。儲存後運行 `docker compose up -d`，再到 Ruri 的「伺服器授權」激活。

Windows Docker Desktop 用戶可在宿主機 PowerShell 中、Compose 檔案所在目錄執行 `(Get-CimInstance Win32_ComputerSystemProduct).UUID | Set-Content -Encoding ascii ./ruri-host-id`，然後將上例最後一行換成 `./ruri-host-id:/run/ruri-host/machine-id:ro`。容器重建時保留這個檔案；換機器時按[授權與換機說明](#伺服器授權與帳號)重新激活。未提供可用宿主機標識時，管理員仍可使用網頁和 WebDAV，授權功能會提示暫不可用。

帳號、作品資料、設定和授權儲存在 `ruri-data` 數據卷中。**升級時保留數據卷，不運行 `docker compose down -v`**。音影片原檔案仍在主機的媒體目錄；備份或換機要分別處理應用資料和媒體。

### 首次設定管理員密碼

把安裝步驟中取得的設定碼填入首次設定頁面，再輸入兩遍自己的新密碼。設定完成後用 `admin` 和新密碼登入；設定碼只使用一次，之後不再作為密碼。

已有安裝繼續使用原來的帳號和密碼。如果忘記密碼，按[重置管理員密碼](#重置管理員密碼)操作。不要為了找回密碼刪除應用數據目錄或 Docker 數據卷。

要修改自己的密碼，在「帳戶與會話 → 修改密碼」輸入當前密碼，再輸入兩遍新密碼。管理員給其他用戶創建或重置密碼時，也需要輸入兩遍。

## 升級現有安裝

- **Linux**。通過 `install.sh` 安裝的服務，在新版本的解壓目錄再次運行 `sudo ./install.sh` 即可升級。腳本會重啓服務，繼續使用 `/var/lib/rurimecha` 中的數據。手動啓動的安裝先停止 Ruri，解壓新版後用原來的 `-data-dir` 參數啓動。
- **Docker**。在原 Compose 目錄的 `.env` 中將 `RURI_IMAGE` 改為發行頁上的新鏡像，再運行 `docker compose pull core` 和 `docker compose up -d core`。繼續使用原有的數據卷與媒體掛載。
- **Windows 客戶端**。打開窗口頂部的「Ruri → 檢查更新」，確認下載，按提示完成安裝。重新打開客戶端後會繼續使用原來的媒體庫。

Ruri 會在啓動時自動升級支持的數據庫。需要升級數據庫時，數據目錄下會儲存一個名為 `core.db.before-v…` 的備份資料夾。升級完成後，用原帳號登入即可繼續使用。若啓動失敗，請保留數據目錄，檢查空間和寫入權限，並根據啓動提示核對版本後再重試。

## Windows 卸載

先在系統托盤中選擇「退出 Ruri」，再到 Windows 設定的「已安裝的應用」中卸載 **Rurimecha**。卸載嚮導預設保留應用數據，重新安裝後可繼續使用原來的媒體庫。

需要重新開始時，在卸載嚮導中勾選「同時清除本機 Ruri 應用數據」。這會永久刪除 `%LOCALAPPDATA%\Rurimecha\data` 中的帳戶、媒體庫資料、收藏、進度、儲存到 Ruri 的台本、設定和本機授權資訊；媒體來源目錄中的音影片原檔案保留。需要保留資料時，請先導出遷移包；需要釋放換機授權時，先在「伺服器授權」反激活。升級程序不會執行這項清理。

數據目錄含有鏈接或仍被 Ruri 使用時，清理會失敗；請先退出 Ruri，並核對數據目錄後重試，不要刪除鏈接指向的媒體目錄。

## 添加媒體目錄

1. 登入管理員帳號，在首頁點擊「添加媒體路徑」，選中伺服器上存放音聲或影片的目錄。Windows 桌面版會打開系統資料夾選擇窗口；用瀏覽器連接 Windows 伺服器時，可先選擇磁盤再打開資料夾，也可以輸入 `C:\Music` 這樣的完整路徑。Docker 用戶可選 `/media/library`。
2. 選擇需要的自動操作。「自動掃描」查找檔案，「自動歸檔」把檔案整理成作品，「自動刮削」為已有 RJ 編號的作品獲取資料，「自動提取媒體資訊」讀取時長、音軌等資訊。
3. 添加後，從媒體來源打開目錄即可瀏覽檔案。要集中查看整理好的內容，進入作品庫。等待期間可在「後台任務」查看進度和結果。

需要調整自動操作時，在目錄頁打開「目錄操作 → 自動處理」。各項可獨立開關。關閉自動掃描後仍可手動掃描，已開啓的其他操作可以使用已有的掃描結果。歸檔需要先完整掃描目錄，讀取時長等資訊只需先發現檔案。

移除媒體目錄會清除該目錄在庫里的作品、手工整理結果和相關收藏或播放清單條目。原檔案留在磁盤上。可以把媒體放在已掛載的硬盤或網絡目錄，應用數據目錄建議放在伺服器的本機磁盤。

如果已有 kikoeru 兼容音聲庫，添加來源時將「來源類型」選為「kikoeru 兼容服務」，填寫服務地址。添加後可瀏覽並選擇作品加入自己的媒體庫。若要把檔案儲存到伺服器，請填寫「伺服器下載目錄（可選）」後再按需儲存。

瀏覽兼容來源時，右上角搜索用於查找作品；手機上先點搜索圖標展開輸入框，輸入後按鍵盤搜索鍵或點搜索按鈕。切換到「社團」「標籤」或「聲優」可瀏覽該類條目，在頁面內的搜索框輸入名稱可篩選條目；點條目查看對應作品，返回後可繼續瀏覽原列表。

兼容來源的目錄和媒體資訊在加入作品時取得。需要重新整理作品時，在該來源的目錄菜單點「重新歸檔」；無需另選掃描或提取媒體資訊。已設為「普通目錄」的資料夾不會因此變回作品；要重新按編號判斷，先在該資料夾菜單點「恢復自動判斷」。

在目錄中將資料夾設為「獨立作品」或「普通目錄」後，等待重新歸檔完成，列表會自動更新；未完成時可到「後台任務」查看結果。切換到其他頁面再返回目錄，會從來源列表開始。目錄中的臨時搜索和篩選只在本次瀏覽中保留；需要下次繼續使用時，點「儲存篩選」。

## 找作品和選版本

在搜索框輸入標題、聲優、社團或 RJ 編號。輸入 `RJ12` 這類編號開頭即可找到以它開頭的作品。輸入至少兩個字符並稍等，會顯示候選。同一編號存了多份時，可按候選里的來源和目錄區分。按回車或點「搜索」查看完整結果。只記得標題時，在「搜索範圍」選「僅標題」，作品已儲存的各語言標題都可以用來搜索。

作品庫中的搜索和篩選在切換到其他頁面後清除；作品類型、排序和顯示方式繼續保留。返回作品庫時可重新選擇條件。

作品卡的標籤預覽固定兩行，可見標籤會盡量排滿；點「全部標籤」查看剩餘標籤。缺少社團或聲優時顯示對應圖標和「未知社團」或「未知聲優」；沒有標籤時顯示「未知標籤」和「全部標籤（0）」，該佔位不可點。作者按聲優顯示。相同寬度的作品卡保持等高。

已關聯的原作和其他語言版本會出現在同一個作品庫入口。點「查看其他商品版本」可以分別做以下操作。

1. 在「選擇伺服器副本」中選中要播放或管理的目錄。有多個同號副本時，可按來源和路徑區分。
2. 點「伺服器播放」收聽這份檔案，或點「打開伺服器檔案」查看目錄。管理員可通過「打開伺服器檔案與編輯資料」修改對應作品的資料。
3. 在「商品版本」和「資料語言」中選擇要看的資料。比如可以繼續聽日文原版，同時閱讀中文介紹。標為「僅有商品資料」的版本暫時沒有伺服器檔案可播放。

要設定預設播放哪個版本，在帳號菜單打開「外觀與瀏覽偏好」，選擇「原作優先」或「按版本語言偏好」。想給某一部作品單獨指定版本，可在詳情頁點「設為優先版本」。使用「恢復跟隨全局偏好」可以取消單獨指定。

通過搜索完整編號、打開具體檔案或選擇一條收聽記錄時，Ruri 會打開你選中的內容。查看其他版本的資料也不會切走當前播放。

## 獲取和編輯作品資料

### 從 DLsite 獲取資料

管理員可在「刮削設定」開啓「獲取作品資料」，並點擊「測試 DLsite 連接」確認可訪問。啓用後可為帶有 DLsite 音聲編號（RJ）的作品獲取標題、封面和介紹。

### 查看、修改和更新語言

首次安裝預設查找簡體中文和日文。需要繁體中文或英文時，可以在「刮削設定」選擇。可獲取哪些語言取決於資料來源。

- 在作品詳情的「查看資料」中選擇語言，可一起切換標題、介紹、人員、標籤、價格和圖片等資料。沒有的字段會顯示為未提供。
- 自己改資料時，在「編輯作品資料」選中要修改的語言後再儲存。修改只應用於該語言。
- 資料標為「未知」時，可在「編輯作品資料」打開「未知」並點「設定未知資料的語言」。目標語言已有資料時，選「合併」只補缺少的內容，選「覆蓋」會替換該語言整份資料。
- 只更新某種語言時，打開作品的「分項刷新 → 強制刷新商品資料」，選擇「本次獲取的語言」。其他語言會保留。如有失敗，可在任務結果點「重試失敗項」。
- 只缺封面或圖片時，在「分項刷新」選擇補齊圖片。該菜單也可用於重新下載圖片、獲取媒體資訊、掃描檔案或重新歸檔。

在電腦上可拖動選擇標題、資料、路徑或提示，按 Ctrl+C 複製。macOS 使用 Command+C。手機上長按文字即可選擇複製。

## 收藏集與播放清單

從作品菜單選擇「加入收藏集」，可把整部作品收錄到已有或新建的收藏集中。打開收藏集，可像作品庫一樣瀏覽封面卡片或切換列表，點擊作品查看資料和檔案；作品資料更新後，收藏集中也會顯示最新內容。

從單個音影片或珍藏片段的菜單加入收藏集時，它會收在這個收藏集的「拾音」中。「拾音」使用作品式封面卡片，打開後可以瀏覽、播放、加入佇列或添加到播放清單。移出收藏只移除收錄記錄，原檔案和原作品歸屬會保留。

「智能發現」中的合集會隨媒體整理結果更新，同樣按作品和「拾音」瀏覽。點擊「儲存為收藏集」，填寫名稱並儲存，即可得到能自行增刪的收藏集。儲存時收錄的範圍會保留，其中作品的資料和內容仍隨原作品更新。如果頁面提示只收錄了部分內容，儲存也只包含頁面已收錄的部分。

需要保留具體曲目、刪減範圍、重復曲目和播放順序時，使用播放清單。在當前佇列中選擇「儲存為播放清單」；「收錄到收藏集」則收錄整部作品和單獨添加的音影片。

打開播放清單後，點「播放全部」從頭播放；直接點一條音影片會從該條開始，按完整清單順序繼續播放。前面的項目仍可透過「上一首」返回。點「更多播放方式」可隨機播放全部、把整張清單加入佇列；搜尋後還可選擇僅播放搜尋結果。直接點搜尋結果仍從該條開始播放完整清單。

單條選單提供「只播放此項」、下一首播放、加入佇列、查看檔案資訊或作品，以及「從這裡加入…」，可將該條及後續項目放到下一首或佇列末尾。組合標題只用於展開；透過組合選單播放本組。無法播放的項目不能點播；編輯播放清單不會改變正在播放的佇列。

舊版自定義收藏集會在升級後出現在播放清單中，原有編排會保留。曲目過多時會按順序拆成多個帶編號的列表。未儲存過具體曲目的作品按升級時的內容展開；無法還原的項目會在列表中顯示說明，已儲存但暫時找不到的檔案顯示為不可用。

## 播放與續聽

在作品或資料夾里選擇音影片播放。同一作品提供多個播放版本或格式時，可在播放前選擇，例如帶音效版或 WAV。常聽內容可以加入佇列、播放清單或收藏集。要從上次的位置繼續，可從帳號菜單打開「收聽記錄」。

音訊播放頁、底部播放欄、台本浮窗和本機播放器提供「後退 10 秒」「前進 10 秒」按鈕，每點一次跳轉 10 秒，也可拖動進度條選擇位置。暫停時跳轉會保持暫停；未讀取到時長或正在載入時，請稍候再操作。

播放音訊時，帶時間軸的台本會顯示當前句。手機竪屏可上下拖動台本頂部的橫條，調整封面和台本各自佔用的空間；輕點橫條可在當前句和多句台本之間切換。橫屏可拖動台本側邊的竪條調整寬度，輕點竪條收起台本。

網頁版窗口較寬且有足夠高度時，開始播放音訊會在右下角展開台本浮窗。拖動浮窗頂部橫條可調整高度，輕點橫條收起；收起後，可點底部播放器的「台本字幕」重新打開。切換作品庫、目錄或作品詳情時，浮窗會保持顯示並繼續播放。浮窗中可調整台本時間，點曲目可打開同時顯示封面和台本的完整播放頁。

拖動進度條可以查看目標時間和可用的畫面預覽。在「播放選項」中可切換字幕、音軌或跳到章節。看不到音軌或章節時，請先為檔案獲取媒體資訊。

在 Android 播放音訊時，可打開帶時間軸的台本並點擊「懸浮字幕」。首次使用時允許 Ruri「顯示在其他應用上層」，返回後再點一次。切到其他應用時，字幕會隨播放浮在屏幕上。上下拖動字幕可調整位置，點旁邊的 × 可關閉。

觀看影片時可點「全屏播放」。在網頁端按空格暫停或繼續，按方向鍵跳轉，按 Esc 退出全屏。Android 可輕點畫面顯示控件，雙擊左側或右側跳過 10 秒。睡前可以在播放器設定「睡眠定時」。

管理員可從播放器的台本菜單選擇「新建台本」或「編輯／轉換台本」，並在儲存前預覽。媒體目錄只讀時，可選擇「儲存到 Ruri」。要把台本和音影片放在一起，請選擇儲存到媒體目錄，並確認目錄可寫。轉換格式時請先檢查時間和樣式。

### 準備音影片工具

Linux、Windows 和 Docker 發行版自帶 FFmpeg 和 FFprobe。支持的本地檔案可使用兼容轉碼、音量標準化、畫面預覽、指定音軌和內嵌字幕；能否使用取決於檔案格式和已讀取的媒體資訊。kikoeru 相容來源的影片可選擇支援的轉碼畫質。Linux 用戶請完整解壓發行包，並將 `media-tools` 資料夾與 Ruri 程序放在同一目錄。

管理員可在管理頁打開「解析工具」查看工具是否可用。若要改用自行安裝的工具，請選擇支持 `fd` 輸入的版本，填寫兩個程序的完整路徑，測試通過後儲存。清空兩個路徑並儲存可恢復預設選擇。也可在該頁聯網自動下載工具，伺服器需要約 500 MB 可用空間。

### 用其他播放器或檔案管理器連接

在支持 WebDAV 的播放器或檔案管理器中新建連接，填寫：

| 項目 | 填甚麼 |
| --- | --- |
| 地址 | `http://服务器地址:端口/dav/`；已開啓 HTTPS 時改用 `https://证书对应的服务器名称:端口/dav/` |
| 用戶名、密碼 | 你在 Ruri 中使用的當前帳號和密碼，不是首次設定碼 |
| 路徑 | 已在完整地址中填寫 `/dav/` 時，不要再重復追加 |

例如伺服器是 `192.168.1.20`，對外端口是 `18080`，填寫 `http://192.168.1.20:18080/dav/`。通過下文 Nginx 教程連接時可填 `https://ruri.example.com/dav/`。帳號要有訪問資格；未激活伺服器授權時只有內置管理員可用。

連接後可按資料夾瀏覽並播放原檔案，不能上傳、刪除或改名，也不會把第三方播放器的收聽進度同步到 Ruri。新加的檔案先在 Ruri 中掃描，之後才會出現在 WebDAV 里。播放格式取決於所用播放器，WebDAV 不轉換音影片格式。

**Windows 檔案資源管理器怎麼添加。** 打開「此電腦」，選擇「添加一個網絡位置」（有些版本在右鍵菜單或頂部菜單中），選擇自定義位置，輸入完整 WebDAV 地址，再填寫 Ruri 帳號。直接把地址粘貼到瀏覽器或資源管理器地址欄，不等於已經添加了網絡位置。

**HTTP 能在播放器使用，為甚麼 Windows 卻拒絕掛載？** Windows 的 WebClient 組件預設只允許在 HTTPS 下使用帳戶密碼認證。Ruri 的 HTTP 地址可能被它拒絕，表現為反復詢問密碼、網絡名稱找不到或錯誤 67；這不一定是 Ruri 的密碼有誤。可選做法如下：

- 使用能直接連接 HTTP WebDAV 的播放器或檔案管理器，無需修改 Windows 設定。
- 啓用 Ruri HTTPS，或按 [Nginx 教程](#通過-nginx-訪問-ruri)提供 HTTPS 入口。填寫證書包含的名稱，並讓 Windows 信任證書；不要只忽略瀏覽器的證書警告後就認為資源管理器也會接受。
- 只在可信家庭網絡使用 HTTP、並希望繼續使用資源管理器時，可允許 Windows 對 HTTP 發送帳戶密碼。先按 Win+R，輸入 `services.msc`，確認 **WebClient** 服務存在。以管理員身份打開 PowerShell，執行：

  ```powershell
  New-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Services\WebClient\Parameters' -Name BasicAuthLevel -PropertyType DWord -Value 2 -Force
  Restart-Service WebClient
  ```

  這會對該 Windows 系統的 WebDAV 連接生效，HTTP 連接中的密碼沒有加密。重啓服務會中斷已連接的 WebDAV 位置，之後重新連接。以後恢復為僅允許 HTTPS 時，把命令中的 `-Value 2` 改為 `-Value 1` 再執行。若系統沒有 WebClient 服務，或設定被單位策略管理，請使用支持 WebDAV 的客戶端，不要通過修改 Ruri 密碼來反復嘗試。[微軟說明](https://learn.microsoft.com/en-us/iis/publish/using-webdav/using-the-webdav-redirector)

其他常見情況：

| 現象 | 可以怎麼處理 |
| --- | --- |
| 普通網頁也打不開 | 先核對伺服器地址、Docker 對外端口、防火牆和「局域網範圍」 |
| 改密碼後仍提示密碼錯誤 | 斷開舊網絡位置；在 Windows「憑據管理器 → Windows 憑據」中移除這台伺服器的舊記錄，再用新密碼連接 |
| 瀏覽器打開 `/dav/` 返回「不支持的方法」 | 用 WebDAV 客戶端添加連接；這個地址用於列檔案，不是網頁目錄頁面 |
| 無法複製較大的檔案，或報 `0x800700DF` | Windows WebClient 有自己的單檔案傳輸上限，HTTPS 也不會取消這個限制。可改用專用 WebDAV 客戶端或播放器；需要調高限制時參考微軟說明中的 `FileSizeLimitInBytes` |
| 只在檔案特別多的目錄中出錯 | Windows WebClient 也有目錄屬性大小上限；優先換用專用客戶端，不必為此移動原檔案 |
| 能瀏覽但不能刪除、上傳或改名 | Ruri WebDAV 只讀，這些操作不受支持 |

## 珍藏片段

珍藏片段入口旁的冠飾徽記表示專屬權益。請先打開一份可播放且已獲取時長的檔案；如頁面提示權益未開啓，聯繫伺服器管理員激活或續期。

1. 在「正在播放」或影片全屏的「播放選項」中點「珍藏片段」。
2. 拖動進度條上的兩個手柄選起點和終點。預設選中當前位置之後的 30 秒，靠近末尾時選中最後 30 秒。可點「放大選區」細調。
3. 點「試聽選段」，確認後選擇「儲存片段」。試聽到終點會停止，儲存或取消後可回到選段前的位置。

在帳號菜單點「珍藏片段」可重聽，也可從「片段操作」加入佇列、播放清單或收藏集，或者調整範圍。刪除片段也會移除列表裡引用的該片段，原音影片仍在。源檔案暫時不可用或專屬權益到期時，片段保留，恢復檔案或續期後可繼續使用。

## 在 Android 上收聽

打開單獨安裝的 Android 客戶端，選擇「搜索局域網伺服器」或手動填寫伺服器地址，然後登入。搜索不到時，檢查手機和伺服器是否在同一局域網，並確認伺服器開啓了自動發現。在線播放需要連接有效授權的伺服器。

無需先播放媒體：在底部「我的 → 播放設定」切換「手機直連來源」。開啓時手機直接連接網絡來源；需要使用伺服器為來源設定的代理，或手機無法直接播放時，請關閉此項。播放期間也可以從播放詳情打開「播放設定」。

### 下載到手機離線收聽

1. 在作品詳情選擇播放版本和格式，點「下載到本機」，勾選要儲存的檔案。也可從檔案菜單下載單個音影片。下載時需登入，且伺服器授權有效。
2. 從連接頁、登入頁或帳號菜單打開「本機媒體庫」，可查看進度、暫停、繼續或取消下載。取消會保留已完成檔案。封面或字幕失敗時可以重試補齊。
3. 下載完成後，即使沒有網絡、退出登入或授權過期，也可在「本機媒體庫」收聽。在線作品詳情的「本機版本」也能打開已下載的檔案。

下載包含音影片原檔案、已有的作品文字、封面和可用的文本字幕。手機需要支持原檔案格式。無法播放時，可選擇伺服器里的其他格式重新下載。預設僅用 Wi-Fi 或有線網絡，關閉限制後可能使用移動數據。一次最多下載 500 個檔案，本機媒體庫最多保留 500 個下載版本。

本機播放支持後台播放、通知控制、循環、隨機、睡眠定時、台本和全屏影片。手機里的佇列、收藏和進度單獨儲存。恢復佇列後先暫停，可確認內容後再播放。「刷新作品資料」只更新文字、封面和字幕，需連接原伺服器、以原帳號登入，且伺服器授權有效。

刪除本機版本只會刪除手機上的副本。退出登入或更換伺服器會保留下載，卸載應用或清除應用數據會刪除本機下載和記錄。換手機後需要重新下載作品。珍藏片段可在連接伺服器時播放。

## 隱私模式與收聽記錄

點擊主界面或播放器上的眼睛按鈕開啓「隱私模式」。封面、圖片和影片會遮住，標題、標籤、檔案名和字幕等文字會以星號顯示。想確認一處內容時，點遮罩上的小眼睛可查看 3 秒。導航、播放和進度條仍可使用，設定會記在當前設備。

Android 在隱私模式下準備使用揚聲器時會先詢問，選擇「繼續播放」後才開始。耳機或藍牙設備斷開時會暫停，重新連接後可手動繼續。如果從通知或媒體鍵發起播放並需要確認，請打開應用。鎖屏和通知也會遮住相關文字和封面。

隱私模式下仍會儲存收聽進度。要清除它，在帳號菜單打開「收聽記錄」，刪除單條或點「清空播放記錄」。對應的續播位置和完成狀態會一起清除。收藏、播放清單、珍藏片段和媒體檔案會保留。刪除正在播放的記錄時，可以繼續聽完這次播放，重新選擇內容播放後會再次記錄。

## 伺服器授權與帳號

未激活或授權到期時，內置管理員仍可登入網頁和 WebDAV。要創建其他帳號、使用官方 Android 客戶端在線播放或使用珍藏片段，請在「伺服器授權」填寫許可證密鑰和伺服器名稱，點擊「激活伺服器」。

授權生效後，管理員可在「用戶管理」創建帳號。用戶可以瀏覽和播放同一個媒體庫，各自儲存收藏、播放清單、偏好、進度和珍藏片段。可在用戶的「訪問權限」停用或啓用帳號。停用會退出該帳號的登入並停止它的 WebDAV 訪問。密碼、角色或授權狀態變化後，按提示重新登入。

激活、更新和反激活時伺服器需要聯網。授權有效期內，Ruri 可以離線使用。續期後可用原密鑰更新授權。要換伺服器，先在舊伺服器反激活，再到新伺服器激活。舊伺服器無法啓動時，聯繫許可證提供者核對購買資訊並釋放綁定。替換同一台機器上的 Docker 容器時，請保留數據卷和已配置的宿主機標識。

在「帳戶與會話 → 登入會話與 WebDAV」可查看當前有效登入的設備名稱、客戶端類型、登入 IP、登入和到期時間，並撤銷不用的登入。IP 記錄的是登入時的地址，切換網絡後不會更新。瀏覽器顯示瀏覽器和系統名稱；Android 顯示設備型號；桌面客戶端可顯示電腦名稱。這裡不儲存已退出或過期的登入歷史。

## 連接與網絡

### 從其他設備訪問

- **Linux 服務**預設可從同一局域網訪問，地址為 `http://服务器的局域网地址:8080/`；無法連接時檢查防火牆是否允許該端口。
- **Windows 桌面版**使用安裝時選擇的監聽地址和端口，首次安裝預設監聽全部 IPv4 地址的 `8080` 端口。要讓手機連接，請在 Windows 防火牆中允許安裝目錄下的 `rurimecha-core.exe` 接收專用網絡的入站連接，再使用電腦的局域網地址和所選端口。若安裝時只選了 `127.0.0.1`，先在「網絡設定」保留本機監聽並增加局域網地址。電腦睡眠、關機或退出 Ruri 後，其他設備無法播放。
- **Docker**按照[端口映射和局域網範圍步驟](#docker-安裝)設定，使用主機地址和對外端口；不使用容器的 `172.x.x.x` 地址。

在「網絡設定」的「局域網範圍」留空時，Ruri 會自動識別直連的私有網段。需要手動填寫時，每行一個網段，例如 `192.168.1.0/24`；Docker、VPN 或跨網段家庭網絡可能需要手動補充，填寫前保留頁面所顯示的原有範圍。

從局域網外訪問時，需要同時開啓伺服器的「允許遠程訪問」，以及「用戶管理 → 訪問權限」中相應帳號的遠程訪問。HTTP 會傳輸未加密的登入和媒體數據，外網使用 HTTPS 或可信 VPN。經過 Nginx 時，訪問範圍按[反代教程](#通過-nginx-訪問-ruri)處理。

### 開啓 HTTPS

在「網絡設定」保留 HTTP，或同時開啓 HTTPS，並分別設定端口。預設 HTTPS 端口為 `8443`。開啓前選擇 PEM 格式的證書和匹配的未加密私鑰檔案；更換時同時選擇這兩個檔案。使用證書包含的名稱或 IP 連接，並讓設備信任該證書。若當前頁面使用 HTTP，請在可信局域網中提交證書檔案。

勾選「強制使用 HTTPS」後，HTTP 會跳轉到 HTTPS，播放器和 WebDAV 客戶端仍應直接填寫 HTTPS 地址。修改地址、端口或證書會中斷連接，儲存前記下新地址，再按提示重新打開。

Docker 還需增加 HTTPS 的端口映射，例如在原有 HTTP 映射下面添加 `"192.168.1.20:8443:8443"`，儲存後運行 `docker compose up -d`。需要 HTTP 自動跳轉時，HTTPS 兩側端口保持一致，避免被跳到沒有映射的端口。通過 Nginx 提供入口時，按下一節設定。

## 通過 Nginx 訪問 Ruri

這部分適合已有 Nginx、域名和證書的用戶。只想在家裡用手機連接時，可以直接使用上一節的局域網地址。

Nginx 可以提供 HTTPS 入口，再通過 HTTP 連接 Ruri；不需要把同一份證書再上傳給 Ruri。同機 Nginx 按下面的示例連接時，無需填寫「可信代理」，Ruri 使用 Docker 橋接部署時也一樣。通過域名登入後，Ruri 按訪客 IP 判斷局域網及帳號遠程訪問權限。

| 連接方式 | 設定方法 |
| --- | --- |
| HTTPS 入口 → HTTP Ruri | 使用下面的示例，證書只配置在 Nginx 中 |
| HTTP 入口 → HTTP Ruri | 同機連接無需填寫可信代理；僅用於可信網絡 |
| HTTPS 入口 → HTTPS Ruri | 同機連接無需填寫可信代理；另配置上游證書校驗 |
| `https://域名/ruri/` 子目錄 | 不支持，請使用獨立域名的根路徑，例如 `https://ruri.example.com/` |

### 示例：同機 Nginx 提供 HTTPS

以下假設 Nginx 和 Ruri 直接運行在同一台 Linux 電腦上，域名為 `ruri.example.com`，家庭網段為 `192.168.1.0/24`。

1. 讓域名解析到 Nginx 所在設備，準備與域名匹配、訪問設備信任的證書。示例路徑為 `/etc/nginx/certs/ruri-fullchain.pem` 和 `/etc/nginx/certs/ruri-key.pem`。
2. 同機 Nginx 無需填寫「可信代理」。只通過同機 Nginx 訪問時，可在 Ruri 的「網絡設定」讓 Ruri 僅監聽 `127.0.0.1`，HTTP 端口保留 `8080`。若需調整局域網訪問範圍，在「局域網範圍」保留原有網段並加入家庭網段，例如 `192.168.1.0/24`，然後儲存。
3. 在 Nginx 的配置目錄新建 `ruri.conf`，例如 Debian/Ubuntu 的 `/etc/nginx/conf.d/ruri.conf`，填寫：

```nginx
server {
    listen 80;
    server_name ruri.example.com;
    return 308 https://ruri.example.com$request_uri;
}

server {
    listen 443 ssl;
    server_name ruri.example.com;
    ssl_certificate     /etc/nginx/certs/ruri-fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/ruri-key.pem;

    client_max_body_size 257m;
    client_body_timeout 600s;
    send_timeout 600s;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $http_host;
        proxy_set_header X-Forwarded-Host $http_host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header Connection "";

        proxy_buffering off;
        proxy_request_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
        proxy_redirect off;
        gzip off;
    }
}
```

4. 將域名和證書路徑換成自己的值，檢查配置後重新載入：

   ```sh
   sudo nginx -t
   sudo systemctl reload nginx
   ```

5. 用 `https://ruri.example.com/` 登入，儲存一次設定，播放並拖動進度。WebDAV 使用 `https://ruri.example.com/dav/`；換機恢復時通過同一入口上傳遷移包。

上述示例適用於直接接收用戶連接的一層 Nginx。如果前面還有 CDN 或其他代理，須先在 Nginx 中限定並還原這些受信入口的訪客地址，不能直接使用用戶自填的地址頭。可信代理只填自己控制的地址或專用代理網段，不填整個互聯網或普通用戶共用的網段。

外網訪問仍需同時開啓 Ruri 的「允許遠程訪問」和相應帳號的遠程訪問權限。只需家庭使用時保持遠程訪問關閉，也可在 Nginx 的 HTTPS `server` 中額外添加 `allow 192.168.1.0/24; deny all;`。反代上游跨越不可信網絡時，使用 HTTPS 上游或可信隧道。

保留用戶原來的認證資訊、Cookie、`Origin` 和 `Referer`。不要偽造來源繞過登入檢查，也無需另行改寫 Cookie。不要另加佔用 `Authorization` 的 Nginx 帳號密碼認證，以免與 Ruri 和 WebDAV 密碼衝突。WebDAV 列目錄需要 `PROPFIND`，不能只允許 GET/POST。媒體、圖片和登入響應不設定公共快取。

### Docker 與 HTTPS 上游

- **只有 Ruri 在 Docker 中**：使用預設橋接網絡並保留 `127.0.0.1:8080:8080` 的端口映射，宿主機 Nginx 連接 `http://127.0.0.1:8080`，無需填寫「可信代理」，重建容器後也無需手動更新代理地址。Ruri 的「局域網範圍」填寫家庭網段。
- **Nginx 和 Ruri 都在 Docker 中**：加入同一個專用 Docker 網絡，上游改為 `http://core:8080`；`127.0.0.1` 指 Nginx 容器自身。可信代理填寫 Nginx 容器的固定 IP，或該專用代理網絡的網段；不要信任其他用戶容器共用的網絡。Ruri 無須向主機發佈端口，訪問設備使用 Nginx 的地址。
- **需要 HTTPS 上游**：先在 Ruri 啓用 HTTPS，上游改為 `https://127.0.0.1:8443`（容器間為 `https://core:8443`），另加以下設定。`ruri.example.com` 必須包含在 Ruri 上游證書中；家庭自建證書應改填其根證書檔案，不關閉校驗。

  ```nginx
  proxy_ssl_server_name on;
  proxy_ssl_name ruri.example.com;
  proxy_ssl_verify on;
  proxy_ssl_trusted_certificate /etc/ssl/certs/ca-certificates.crt;
  proxy_ssl_verify_depth 3;
  ```

### 常見問題

| 現象 | 先檢查甚麼 |
| --- | --- |
| 登入或儲存返回 403 | 訪客是否滿足局域網及帳號訪問權限；是否按示例填寫代理配置；其他設備或容器中的代理是否填寫了可信地址 |
| 反復跳轉或跳到 `8443` | 是否按示例填寫代理配置；其他設備或容器中的代理是否填寫了可信地址；只由 Nginx 提供 HTTPS 時，無需開啓 Ruri 的強制跳轉 |
| 502 | Ruri 是否運行、端口或容器地址是否正確；使用 HTTPS 上游時再檢查證書名稱與信任根 |
| 頁面能開，播放卡住或不能拖動 | 保留 `Range`，關閉媒體快取和緩衝，並確認直連 Ruri 能播放 |
| 上傳遷移包報 413 | 核對 `client_max_body_size`；Ruri 也有包大小上限 |
| WebDAV 無法列目錄 | 使用 `/dav/`；保留認證資訊，並允許 `PROPFIND` |


## 換機與恢復

1. 在舊伺服器用管理員帳號打開「遷移與恢復」。只帶走作品資料時，選擇「全部作品資料」。要連同帳號、設定、收藏和進度一起帶走時，選擇「系統數據和全部作品資料」。也可只導出系統數據。含系統數據的包需要設定密碼，請儲存好包和密碼。
2. 把媒體硬盤接到新設備，或把資料夾複製到新設備。安裝 Ruri 並登入後，打開「遷移與恢復」，選擇遷移包，填寫新的媒體目錄，再點擊「預覽恢復」。
3. 核對缺失檔案後點「恢復」。檔案暫時缺失時仍可保留資料、收藏和進度。將檔案放回原來的相對位置並重新掃描後，可恢復播放。如果恢復了系統數據，請重啓 Ruri，使用遷移前的帳號和密碼登入。

只搬一部作品時，從詳情的「遷移此作品」導出。兩台設備上作品在媒體來源中的相對位置相同時，可以從目標作品的同一入口恢復，替換該作品的資料和人工整理結果。目標庫還沒有該作品時，從「遷移與恢復」導入單部作品包。

包內會保留作品資料、原有資料來源、人工編輯和圖片。恢復後，作品仍按原有設定獲取更新。音影片原檔案、日誌、任務記錄、伺服器授權和手機本機下載需要分別處理。

## 重置管理員密碼

- **Linux** 服務安裝運行 `sudo /opt/rurimecha/reset-admin-password.sh --service`。如果服務正在運行，腳本會在重置後重新啓動。手動啓動的安裝請先停止 Ruri，在解壓目錄運行 `./reset-admin-password.sh`，如用了其他數據目錄，將目錄路徑加在命令後，再重新啓動 Ruri。
- **Windows** 先從托盤菜單選擇「退出 Ruri」，再打開安裝目錄（預設是 `%LOCALAPPDATA%\Programs\Rurimecha`），雙擊 `reset-admin-password.cmd`。如使用了其他數據目錄，在該安裝目錄的命令提示符中運行 `reset-admin-password.cmd "数据目录路径"`。完成後重新打開 Ruri。
- **Docker** 在發行版 Compose 檔案所在目錄運行 `./reset-admin-password.sh`。如果 Ruri 正在運行，腳本會暫時停止它並在重置後重新啓動。

使用腳本顯示的用戶名和新密碼登入。用戶名和資料會保留，已用這個帳號登入的設備需要重新登入。

## 遊客體驗

管理員打開「用戶管理」，開啓「遊客體驗」後，訪客可在登入頁點「遊客體驗」瀏覽和播放作品。遊客無法修改作品或儲存收藏與收聽進度。關閉開關後，遊客將無法繼續訪問；再次開啓後可重新進入。公開演示請使用專門的媒體庫，並確認作品允許公開播放。

## 選擇界面語言

在連接頁、登入頁或帳號菜單點語言按鈕，可選擇簡體中文、繁體中文、日本語、English 或「跟隨系統」。登入後也可在「外觀與瀏覽偏好」中修改；該選擇隨帳號儲存，其他設備登入後也會使用。未登入時的選擇只儲存在當前設備；退出帳號後恢復該設備的選擇。本機媒體庫在離線時沿用最近使用的語言。

「跟隨系統」優先使用設備支持的語言；繁體中文地區使用繁體，其他中文地區使用簡體，沒有匹配時使用英語。切換界面語言不會更改作品標題、檔案名、收藏名稱，也不會改變作品資料、音軌和字幕的語言；這些仍在各自的菜單中選擇。

安裝程序目前使用簡體中文。管理和命令行工具主要使用英語；歷史發佈說明提供中文和英文。


## 社團、聲優和畫師

在「社團」「聲優」「畫師」中搜尋名稱，點項目查看本庫作品；圖片使用關聯作品的封面。點作品開啟詳情。在「作品來源」選擇 DLsite 分區可探索其他作品，點結果開啟 DLsite。也可點「探索作品」輸入尚未收錄的名稱，或選擇已設定的相容來源尋找。名稱搜尋可能漏掉作品或包含同名參與者，畫師在相容來源中的結果取決於來源是否支援搜尋其署名。點「重新整理」從第一頁重新取得，失敗後保留目前結果，可點「重試」。探索結果不會自動加入媒體庫或下載檔案。


## 無變化時的自動檢查

僅做定期檢查且未發現變化時，不會重複歸檔、取得作品資料或讀取媒體資訊。既有待辦和等待重試的處理仍會繼續。

## 查看問題與詳細診斷

管理員可在設定中開啟「系統日誌」，預設查看「需要關注」的問題；切換「全部記錄」可查看操作結果，展開詳情可查看回報問題時需要的記錄。工作進度、失敗項目及重試方法在工作詳情中查看。

需要排查問題時，在設定中開啟「詳細診斷」，啟用並儲存後重現問題，再關閉並儲存。開關對整個伺服器生效，重新啟動後保留。關閉後停止新增診斷記錄，已有記錄仍按容量上限保留；在日誌中選擇「診斷記錄」可查看它們。正常使用時無需啟用。


## 收聽統計與推薦

從側邊欄或帳號選單開啟「收聽與推薦」。在「收聽統計」查看收聽時長、日曆、每月趨勢和常聽作品、聲優、社團及標籤，可切換最近 30 天、12 個月、年份或全部時間。這裡只記錄從伺服器媒體庫播放的內容，手機本機媒體庫不計入。

在作品詳情點選「我的評分」，選擇 1～5 星；再次開啟可修改或取消。評分屬於自己的帳號，針對整部歸檔作品，不同格式與播放版本共用。卡片上的「我的評分」與作品公開評分分別顯示。

「為你推薦」提供「可能喜歡」「換換口味」「久未重聽」，點選作品查看詳情或直接播放，點選「換一批」更換推薦。刪除續播記錄不會刪除收聽統計或評分。


### 影片畫質與轉碼限制

觀看影片時，開啟「播放器設定」選擇「影片畫質」。支援轉碼的影片可選解析度和位元率，切換後會從目前位置繼續並重新緩衝；無法轉碼的影片只顯示「原始格式」。本地來源和可讀取的 kikoeru 相容來源影片均可使用。原始格式能否播放取決於裝置。「自動」採用預設畫質預算，不會持續隨網速調整。

管理員可在解析設定限制最高轉碼高度、最大影片位元率及每個工作的最大工作執行緒數。解析度和位元率填 0 表示不限；執行緒數可填 1–64，0 使用單執行緒。限制適用於新轉碼工作，原始格式直接播放不受影響。轉碼保留原檔案、不放大畫面並保留來源影格率。

已結束的任務和執行日誌最多保留 48 小時。任務結束後，可查看未完成項並重試；成功項計入彙總。記錄過期後，可從作品或來源重新操作。作品資料、收藏、收聽進度和字幕草稿不受影響。本次升級不保留舊任務記錄；升級成功後不保留舊資料庫備份。
