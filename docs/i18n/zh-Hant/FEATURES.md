# Rurimecha 功能一覽

Rurimecha（Ruri）適合用來整理自己收藏的音聲、ASMR 和影片。伺服器支持 Linux x86-64、Docker x86-64 和 Windows x64。裝好後用瀏覽器訪問，也可以單獨安裝 Android 客戶端。

## 界面語言

- 軟件和官網支持簡體中文、繁體中文、日語、英語；可手動選擇或跟隨系統。軟件登入後的選擇隨帳號儲存，未登入時儲存在當前設備。作品資料、音軌和字幕語言分別選擇。
- 安裝程序目前使用簡體中文，管理和命令行工具主要使用英語，歷史發佈說明提供中英兩種語言。

## 整理自己的媒體庫

- 在目錄或作品的重新整理選單中，可分別更新資料及圖片、讀取影音資訊、掃描或歸檔。更新資料時可選擇語言，並保留手動修改。掃描及讀取影音資訊適用於本機來源。作品從多個本機來源收錄檔案且沒有自己的資料夾時，可選擇要讀取哪個來源的檔案資訊。
- 目錄中的檔案類型篩選在同一來源內連續瀏覽及暫時切換頁面時保留；切換來源或作品檔案區恢復預設，可主動清除或儲存篩選。
- 在作品裡選「全部檔案」即可查看各播放群組的檔案與附件。點選檔名即可閱讀文字、縮放圖片或翻閱 PDF。
- 可刪除單個作品，保留原始檔並忽略原作品範圍；獨立子作品保留。在設定中統一查看和解除已刪除作品、已忽略目錄，已清除的資料和引用不會恢復。
- 聲優頁可查看公開人物資料與出演作品，開啟本庫副本或前往內置 ASMR.one 尋找；保留本庫聲優與名稱管理。社團、畫師繼續支援本庫瀏覽與外部資料查找。
- 伺服器授權有效時，管理員可在「網路設定」開啟「智慧選路」，嘗試透過其他路線存取 DLsite 和 ASMR Online。能否存取取決於伺服器的網路和所在地區。關閉後仍可查看已儲存的資料。
- 添加存放媒體的資料夾，即可按原目錄瀏覽，也可將檔案整理成作品。可以分別開啓自動掃描、歸檔、獲取作品資料和讀取音影片資訊，也能手工調整作品包含哪些檔案。
- 已提供無法移除的 ASMR.one 來源，可直接瀏覽和選擇作品入庫，並設定代理、下載目錄；與同網址的自建來源並存，聲優頁固定進入內建來源。可瀏覽或輸入伺服器下載目錄，儲存時會檢查能否寫入。
- 可以連接 kikoeru 兼容的音聲庫，搜索作品或瀏覽、搜索社團、標籤和聲優條目，選擇作品加入自己的媒體庫，並按需將檔案儲存到伺服器。
- 兼容來源的作品可按目錄樹勾選資料夾或檔案，依副檔名批次選取後儲存到伺服器；保留原目錄結構、略過完整副本，支援進度查看、停止與重試未完成項。
- 按標題、聲優、社團、標籤或作品編號查找。輸入部分 RJ 編號就能看到候選。只記得標題時，可縮小到「僅標題」。
- 可從 DLsite 取得有 RJ 編號的作品資料，也可以自己修改標題、簡介和圖片。簡體中文、繁體中文、日文和英文資料可以同時儲存，單獨查看或更新。
- 關聯的原作與其他語言版本可以一起瀏覽。一個商品存了多份檔案時，可選擇具體目錄。可設定優先播放原作或指定語言版本，同時使用另一種語言閱讀介紹。
- 可選擇並複製界面上的標題、路徑和作品資料。
- 新增 Kikoeru 相容來源時，填寫網站位址和選用代理後，可先按「測試連線」再儲存。已有來源也能測試。成功表示可以瀏覽來源，不代表所有音訊都能流暢播放。
- 播放尚未完整儲存到伺服器的 ASMR.one 音訊時，可選擇「流暢優先」或「品質優先」。流暢優先在有較小版本時使用它；品質優先播放所選原檔。切換後從目前進度繼續。完整儲存後使用本機原檔，不再顯示這組選項，下載也始終保留原檔。目前曲目完整緩衝後才預載下一首。

## AI 翻譯和歸檔建議

- 伺服器授權有效時，管理員可在「AI 配置」使用本機或遠端閘道。本機可新增及測試供應商的模型，遠端可使用位址及存取權杖連接，再分別為各項功能選擇模型。
- 在 Android 本機媒體庫開啟「AI 設定」。選擇「本機閘道」可新增供應商、輸入金鑰、取得模型和測試連線，也可使用遠端閘道。每個閘道會保留各自的模型選擇。儲存後可從作品詳細資料開始翻譯。使用雲端模型時，手機仍需連線。
- 在本機閘道的管理頁查看最近的模型呼叫及供應商回報的詞元用量。
- 可翻譯台本、作品資料及目錄和檔案顯示名稱，或產生歸檔建議。目錄與作品可批次翻譯收錄名稱，選擇目標語言和是否略過已有譯名即可開始。點選按鈕可切換原名和目前介面語言的譯名。

## 播放、續聽和收藏

- 從作品或目錄播放音影片。可按作品提供的版本與格式選擇檔案，例如有無音效、MP3 或 WAV。
- 音訊與影片優先使用同目錄的同名字幕，也可選擇同作品、同來源內其他資料夾的同名字幕；登入使用者的手動選擇或關閉狀態隨帳號為目前檔案儲存。
- 播放時可查看字幕和台本、設定睡眠定時、從最近的進度繼續，也可以把常聽內容整理進收藏集或播放清單。管理員可手工新建、編輯和轉換台本。
- 收藏集按作品封面卡片或列表瀏覽，單獨收錄的音影片和珍藏片段集中在「拾音」中。智能發現合集採用相同形式，可直接另存為自己的收藏集。
- 播放清單儲存具體曲目、重復曲目和播放順序；可從點選項目繼續播放完整清單，也可只播放單條、播放搜尋結果、隨機播放或將後續項目加入佇列。舊版自定義收藏集升級後轉為播放清單。
- 音訊播放頁、底部播放欄、台本浮窗和本機播放器支持前進／後退 10 秒，暫停時跳轉保持暫停。
- 載入或緩衝時仍可點按暫停。播放頁可點已顯示的作品名開啟詳情；進度條支援螢幕朗讀目前時間與總時長。
- 音訊播放頁可直接查看當前句，並調整台本佔用的空間；網頁版開始播放音訊時可在右下角看到台本浮窗，繼續瀏覽其他頁面。
- Android 播放帶時間軸的台本時，可以開啓懸浮字幕，在 Ruri 內和其他應用上方繼續看字幕，解鎖後繼續顯示；輕點字幕可顯示關閉按鈕。
- Windows 桌面客戶端可從開始菜單打開。
- 在「設定 → 版本與更新」查看版本和檢查更新。Android 也能從連線頁檢查應用程式，Linux 和 Docker 依照主機的安裝方式升級。
- Windows 安裝精靈和 Linux 終端安裝可選擇監聽 IP、連接埠並檢查是否可用。Windows 可選擇安裝後建立桌面捷徑。解除安裝預設保留應用程式資料，可勾選清除，媒體原檔保留。
- 啟用目前使用的伺服器或手機授權後，可把喜歡的一段音影片選出來試聽、儲存，再單獨播放或加入列表。珍藏片段沿用原檔案，播放時需要原檔案可用。
- Linux、Windows 和 Docker 發行版自帶音影片工具，啓動即可使用音量標準化、兼容轉碼和內嵌字幕。[音影片工具](USAGE.md#準備音影片工具)
- 也可用支持 WebDAV 的播放器瀏覽資料夾並播放原檔案，使用 Ruri 的帳戶密碼連接。檔案以只讀方式提供；可選擇證書檔案啓用 HTTPS，分別設定 HTTP、HTTPS 端口，並讓 HTTP 訪問跳轉到 HTTPS。

### 影片畫質與轉碼限制

觀看影片時，開啟「播放器設定」選擇「影片畫質」。支援轉碼的影片可選解析度和位元率，切換後會在目前位置緩衝，再繼續播放。無法轉碼的影片只顯示「原始格式」，能否播放取決於裝置。本機來源和可讀取的 kikoeru 相容來源影片均可使用。「相容播放」的「自動」使用預設畫質，連線變慢時可手動選擇較低畫質。

## 手機上聽和隱私模式

- Android 首頁可直接開啟「本機媒體庫」或「連線至伺服器」。本機庫可新增手機裡的媒體資料夾，依目錄或作品查找並播放。無法連線時，可在伺服器選擇畫面搜尋區域網路內的 Ruri 或手動填寫位址。支援背景播放、媒體鍵、全螢幕影片和還原佇列。
- Android 本機媒體庫可分項重新整理目錄和作品、讀取媒體資訊、查看背景任務，並瀏覽 ASMR.one 或新增 Kikoeru 相容來源。可從作品選擇要下載到手機的檔案。
- Android 本機播放設定可測量音軌並標準化音量、產生裝置支援的相容副本，以及擷取完整的內嵌文字字幕並儲存為 WebVTT。
- 登入伺服器後，可把原檔、作品文字、封面和可用的文字字幕下載到手機。從「下載任務」查看進度，在本機媒體庫的「已下載媒體」來源收聽新舊下載。「下載儲存位置」可為後續下載選擇手機資料夾，已有檔案會保留在原位置。
- 開啓隱私模式可遮住封面、影片和作品文字，點小眼睛可臨時查看 3 秒。Android 還能在外放前詢問，耳機或藍牙設備斷開時暫停。
- 從帳號菜單可刪除一條收聽記錄或清空自己的記錄。清除記錄也會清除對應的續播位置。

## 多人使用和換機

- 首次設定由隨機預設管理密碼保護；Windows 桌面視窗自動填寫，網頁提供 Windows、Linux 和 Docker 取得說明。設定自己的密碼後進入媒體庫，預設管理密碼隨即失效。
- 測試期間可在官網填寫自己的信箱自動領取免費測試授權，每信箱一次。發放後 7 天內啟用，首次啟用後可使用 31 天；未收到郵件可稍後重試或查詢已有授權。
- 伺服器授權有效時，管理員可在「使用者管理」建立帳號，其他帳號可登入使用。各帳號共用媒體庫，各自儲存收藏、播放清單、偏好和收聽進度。
- 管理員可調整局域網範圍、為指定帳號開啓遠程訪問，也可通過 Nginx 使用 HTTPS 入口連接 HTTP 伺服器。同機 Nginx 無需填寫可信代理，Ruri 使用 Docker 橋接部署時也一樣。
- 在登入會話中查看設備名稱、客戶端類型、登入 IP 和時間，撤銷不用的登入。
- 管理員可備份系統數據，或導出全部作品及單部作品的資料。換機後可選擇新的媒體目錄恢復。暫時找不到的檔案仍可保留作品資料，待檔案放回後重新掃描。
- 伺服器授權有效時，管理員可啟用遊客體驗，也可隨時關閉；遊客免密碼瀏覽和播放演示媒體，不能儲存個人內容，關閉後遊客登入失效。
- 管理員可查看需要關注的問題和操作結果；排查時可在設定中啟用詳細診斷，完成後關閉。
- 已結束的任務和執行日誌最多保留 48 小時。任務結束後，可查看未完成項並重試，成功項目會計入總數。記錄過期後，可從作品或來源重新操作。作品資料、收藏、收聽進度與字幕草稿仍可繼續使用。

## 收聽統計與推薦

- 從側邊欄或帳號選單開啟「收聽與推薦」。在「收聽統計」查看收聽時長、日曆、每月趨勢和常聽作品、聲優、社團及標籤，可切換最近 30 天、12 個月、年份或全部時間。本機媒體庫在手機上儲存自己的收聽統計，連接伺服器時可以查看伺服器的統計。
- 在作品詳情點選「我的評分」，選擇 1～5 星；再次開啟可修改或取消。評分屬於自己的帳號，針對整部歸檔作品，不同格式與播放版本共用。卡片上的「我的評分」與作品公開評分分別顯示。
- 「為你推薦」提供「可能喜歡」「換換口味」「久未重聽」，點選作品查看詳情或直接播放，點選「換一批」更換推薦。刪除續播記錄不會刪除收聽統計或評分。

## 適用範圍與限制

- 發行伺服器包支持 Linux/Windows x64，Docker 鏡像為 Linux x86-64；沒有 ARM 發行包。
- 相容來源可播放來源網站提供的檔案。可用的影片畫質、轉碼、內嵌字幕及音量正規化選項，取決於所選檔案與伺服器可用的影音工具。
- WebDAV 只讀，不提供上傳、改名、刪除或收聽進度同步。反向代理使用獨立域名根路徑，不支持子目錄入口。
- 網頁登入在登入會話清單中顯示瀏覽器和系統名稱，可搭配登入時間辨認自己的登入記錄。
