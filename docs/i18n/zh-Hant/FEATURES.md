# Rurimecha 功能一覽

Rurimecha（Ruri）適合用來整理自己收藏的音聲、ASMR 和影片。伺服器支持 Linux x86-64、Docker x86-64 和 Windows x64。裝好後用瀏覽器訪問，也可以單獨安裝 Android 客戶端。

## 界面語言

- 軟件和官網支持簡體中文、繁體中文、日語、英語；可手動選擇或跟隨系統。軟件登入後的選擇隨帳號儲存，未登入時儲存在當前設備。作品資料、音軌和字幕語言分別選擇。
- 安裝程序目前使用簡體中文，管理和命令行工具主要使用英語，歷史發佈說明提供中英兩種語言。

## 整理自己的媒體庫

- 社團、聲優、畫師可按名稱瀏覽本庫作品，使用作品封面顯示；可手動探索 DLsite 和相容來源中的相關作品，並重新整理結果。
- 添加存放媒體的資料夾，即可按原目錄瀏覽，也可將檔案整理成作品。可以分別開啓自動掃描、歸檔、獲取作品資料和讀取音影片資訊，也能手工調整作品包含哪些檔案。
- 可以連接 kikoeru 兼容的音聲庫，搜索作品或瀏覽、搜索社團、標籤和聲優條目，選擇作品加入自己的媒體庫，並按需將檔案儲存到伺服器。
- 按標題、聲優、社團、標籤或作品編號查找。輸入部分 RJ 編號就能看到候選。只記得標題時，可縮小到「僅標題」。
- 可從 DLsite獲取帶 RJ 編號的作品資料，也可以自己修改標題、簡介和圖片。簡體中文、繁體中文、日文和英文資料可以同時儲存，單獨查看或更新。
- 關聯的原作與其他語言版本可以一起瀏覽。一個商品存了多份檔案時，可選擇具體目錄。可設定優先播放原作或指定語言版本，同時使用另一種語言閱讀介紹。
- 可選擇並複製界面上的標題、路徑和作品資料。

## 播放、續聽和收藏

- 從作品或目錄播放音影片。可按作品提供的版本與格式選擇檔案，例如有無音效、MP3 或 WAV。
- 播放時可查看字幕和台本、設定睡眠定時、從最近的進度繼續，也可以把常聽內容整理進收藏集或播放清單。管理員可手工新建、編輯和轉換台本。
- 收藏集按作品封面卡片或列表瀏覽，單獨收錄的音影片和珍藏片段集中在「拾音」中。智能發現合集採用相同形式，可直接另存為自己的收藏集。
- 播放清單儲存具體曲目、重復曲目和播放順序；可從點選項目繼續播放完整清單，也可只播放單條、播放搜尋結果、隨機播放或將後續項目加入佇列。舊版自定義收藏集升級後轉為播放清單。
- 音訊播放頁、底部播放欄、台本浮窗和本機播放器支持前進／後退 10 秒，暫停時跳轉保持暫停。
- 音訊播放頁可直接查看當前句，並調整台本佔用的空間；網頁版開始播放音訊時可在右下角看到台本浮窗，繼續瀏覽其他頁面。
- Android 播放帶時間軸的台本時，可以開啓懸浮字幕，在切換到其他應用後繼續看字幕。
- Windows 桌面客戶端可從開始菜單打開，並在「Ruri → 檢查更新」中下載安裝新版本。
- Windows 安裝嚮導和 Linux 終端安裝支持選擇監聽 IP、端口並檢查是否可用。Windows 卸載時可保留應用數據，或明確選擇清除；媒體原檔案保留。
- 開啓伺服器授權後，可把喜歡的一段音影片選出來試聽、儲存，再單獨播放或加入列表。珍藏片段沿用原檔案，播放時需要原檔案可用。
- Linux、Windows 和 Docker 發行版自帶音影片工具，啓動即可使用音量標準化、兼容轉碼和內嵌字幕。[音影片工具](USAGE.md#準備音影片工具)
- 也可用支持 WebDAV 的播放器瀏覽資料夾並播放原檔案，使用 Ruri 的帳戶密碼連接。檔案以只讀方式提供；可選擇證書檔案啓用 HTTPS，分別設定 HTTP、HTTPS 端口，並讓 HTTP 訪問跳轉到 HTTPS。

## 手機上聽和隱私模式

- Android 客戶端可搜索局域網里的 Ruri，也可手動填寫地址。支持後台播放、媒體鍵、全屏影片和恢復佇列。
- 登入已授權的伺服器後，可把原檔案、作品文字、封面和可用的文本字幕下載到手機。下載完成後，可在「本機媒體庫」離線收聽。本機下載、佇列、收藏和進度由手機單獨儲存。
- 開啓隱私模式可遮住封面、影片和作品文字，點小眼睛可臨時查看 3 秒。Android 還能在外放前詢問，耳機或藍牙設備斷開時暫停。
- 從帳號菜單可刪除一條收聽記錄或清空自己的記錄。清除記錄也會清除對應的續播位置。

## 多人使用和換機

- 內置管理員可使用網頁和 WebDAV。伺服器授權有效時，管理員可以為其他人創建帳號。各帳號共享媒體庫，各自儲存收藏、播放清單、偏好和收聽進度。
- 管理員可調整局域網範圍、為指定帳號開啓遠程訪問，也可通過 Nginx 使用 HTTPS 入口連接 HTTP 伺服器。同機 Nginx 無需填寫可信代理，Ruri 使用 Docker 橋接部署時也一樣。
- 在登入會話中查看設備名稱、客戶端類型、登入 IP 和時間，撤銷不用的登入。
- 管理員可備份系統數據，或導出全部作品及單部作品的資料。換機後可選擇新的媒體目錄恢復。暫時找不到的檔案仍可保留作品資料，待檔案放回後重新掃描。

- 管理員可開啓或關閉遊客體驗；遊客免密碼瀏覽和播放演示媒體，不能儲存個人內容，關閉後遊客登入失效。

- 管理員可查看需要關注的問題和操作結果；排查時可在設定中啟用詳細診斷，完成後關閉。


## 適用範圍與限制

- 發行伺服器包支持 Linux/Windows x64，Docker 鏡像為 Linux x86-64；沒有 ARM 發行包。
- 兼容來源直接播放其提供的檔案；本地檔案的轉碼、內嵌字幕和音量標準化取決於檔案格式與可用工具。
- WebDAV 只讀，不提供上傳、改名、刪除或收聽進度同步。反向代理使用獨立域名根路徑，不支持子目錄入口。
- 瀏覽器不能直接讀取電腦的真實主機名；會話名稱用於辨認登入設備，不能證明設備身份。

## 收聽統計與推薦

- 從側邊欄或帳號選單開啟「收聽與推薦」。在「收聽統計」查看收聽時長、日曆、每月趨勢和常聽作品、聲優、社團及標籤，可切換最近 30 天、12 個月、年份或全部時間。這裡只記錄從伺服器媒體庫播放的內容，手機本機媒體庫不計入。
- 在作品詳情點選「我的評分」，選擇 1～5 星；再次開啟可修改或取消。評分屬於自己的帳號，針對整部歸檔作品，不同格式與播放版本共用。卡片上的「我的評分」與作品公開評分分別顯示。
- 「為你推薦」提供「可能喜歡」「換換口味」「久未重聽」，點選作品查看詳情或直接播放，點選「換一批」更換推薦。刪除續播記錄不會刪除收聽統計或評分。


### 影片畫質與轉碼限制

觀看影片時，開啟「播放器設定」選擇「影片畫質」。支援轉碼的影片可選解析度和位元率，切換後會從目前位置繼續並重新緩衝；無法轉碼的影片只顯示「原始格式」。本地來源和可讀取的 kikoeru 相容來源影片均可使用。原始格式能否播放取決於裝置。「自動」採用預設畫質預算，不會持續隨網速調整。

已結束的任務和執行日誌最多保留 48 小時。任務結束後，可查看未完成項並重試；成功項計入彙總。記錄過期後，可從作品或來源重新操作。作品資料、收藏、收聽進度和字幕草稿不受影響。本次升級不保留舊任務記錄；升級成功後不保留舊資料庫備份。
