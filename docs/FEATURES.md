# 当前功能与限制

首版服务器提供 Linux x86-64、Docker x86-64 和 Windows x64。通过浏览器打开媒体库。

- 扫描、归档、刮削与媒体信息提取分别开关；后续处理可使用手动扫描或已有结果，没有可处理内容时等待。
- 可选择并复制界面上的展示文本。
- 扫描、监听媒体目录，整理作品与播放内容；支持手工调整归属和资料。
- 浏览中日英文资料，按编号、标题、制作人员与标签搜索。可保存收藏、播放列表和收听进度。
- 缓存站和 DLsite 可独立开启、调整顺序并测试连接；简体、繁体、日文、英文资料可分别获取并同时保存。作品中可切换完整资料语言、单独重新获取一种语言，或重试未完成的语言。
- 缓存站保存文字元数据，按编号补取缺失资料，支持语言/字段选择、容量与每日新增限制。不提供手工编辑或图片下载。
- 音视频播放、转码、字幕、睡眠定时、珍藏片段和只读 WebDAV；需要的媒体工具由管理员安装。
- 管理员创建账户，普通用户共享浏览和播放，个人状态分别保存。不开放自行注册。
- 管理员可导出和恢复系统数据、全部作品资料或单部作品资料。换机后可重新指定媒体目录，缺失文件仍保留资料。
- 隐私模式可一键遮蔽图片、视频与内容文字，支持局部查看 3 秒。最近收听支持删除单条或清空本人记录。
- 数据目录格式不兼容时会拒绝启动，不自动转换或清空旧数据。请依据对应版本说明选择新的数据目录。
- 可调整端口、监听地址和局域网范围，并按账号允许远程访问。
- 管理员可在线激活、更新或反激活服务器授权。授权在有效期内可离线使用。未授权时，内置管理员可使用网页和 WebDAV。
- 珍藏片段需要有效服务器授权。可选择音视频起止时间、试听并保存，随后加入队列、播放列表或收藏集。片段播放需要服务器安装 FFmpeg，源文件须可用且已获取媒体时长。

## 关联版本

已关联的原作与语言版本共用作品库入口。可分别选择资料显示语言和播放的文件副本。尚未收录文件的版本可以查看资料。不同副本各自保留人工修改、收藏和播放关系。

- 作品库按商品版本语言偏好或原作优先直接打开合适版本，卡片播放使用同一服务器副本。每部作品可单独设优先版本或恢复全局偏好；详情可查看其他商品版本和切换服务器副本。资料显示语言、正在播放的内容及 Android 本机下载独立。

## Android 客户端

Android 客户端独立于服务器安装包。连接已授权的服务器后，启用的账户可用它浏览和播放。客户端支持局域网搜索、后台播放、媒体键、全屏视频和外放前确认。恢复队列时先暂停，确认文件可用后再播放。

下载可包含原文件、作品文字、封面和文本字幕。下载完成后，本机媒体库无需登录或有效授权即可浏览和播放。本机下载和收听记录请在换机时单独处理，本机队列、收藏和进度不与服务器同步。
