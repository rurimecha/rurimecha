# Rurimecha 功能一览

Rurimecha（Ruri）适合用来整理自己收藏的音声、ASMR 和视频。服务器支持 Linux x86-64、Docker x86-64 和 Windows x64。装好后用浏览器访问，也可以单独安装 Android 客户端。

## 界面语言

- 软件和官网支持简体中文、繁体中文、日语、英语；可手动选择或跟随系统。软件登录后的选择随账号保存，未登录时保存在当前设备。作品资料、音轨和字幕语言分别选择。
- 安装程序目前使用简体中文，管理和命令行工具主要使用英语，历史发布说明提供中英两种语言。

## 整理自己的媒体库

- 社团、声优、画师可按名称浏览本库作品，使用作品封面展示；可手动发现 DLsite 和兼容来源中的相关作品，并刷新结果。
- 添加存放媒体的文件夹，即可按原目录浏览，也可将文件整理成作品。可以分别开启自动扫描、归档、获取作品资料和读取音视频信息，也能手工调整作品包含哪些文件。
- 可以连接 kikoeru 兼容的音声库，搜索作品或浏览、搜索社团、标签和声优条目，选择作品加入自己的媒体库，并按需将文件保存到服务器。
- 按标题、声优、社团、标签或作品编号查找。输入部分 RJ 编号就能看到候选。只记得标题时，可缩小到「仅标题」。
- 可从 DLsite获取带 RJ 编号的作品资料，也可以自己修改标题、简介和图片。简体中文、繁体中文、日文和英文资料可以同时保存，单独查看或更新。
- 关联的原作与其他语言版本可以一起浏览。一个商品存了多份文件时，可选择具体目录。可设定优先播放原作或指定语言版本，同时使用另一种语言阅读介绍。
- 可选择并复制界面上的标题、路径和作品资料。

## 播放、续听和收藏

- 从作品或目录播放音视频。可按作品提供的版本与格式选择文件，例如有无音效、MP3 或 WAV。
- 播放时可查看字幕和台本、设置睡眠定时、从最近的进度继续，也可以把常听内容整理进收藏集或播放列表。管理员可手工新建、编辑和转换台本。
- 收藏集按作品封面卡片或列表浏览，单独收录的音视频和珍藏片段集中在「拾音」中。智能发现合集采用相同形式，可直接另存为自己的收藏集。
- 播放列表保存具体曲目、重复曲目和播放顺序；可从点选条目继续播放完整列表，也可只播放单条、播放搜索结果、随机播放或将后续条目加入队列。旧版自定义收藏集升级后转为播放列表。
- 音频播放页、底部播放栏、台本浮窗和本机播放器支持前进／后退 10 秒，暂停时跳转保持暂停。
- 音频播放页可直接查看当前句，并调整台本占用的空间；网页版开始播放音频时可在右下角看到台本浮窗，继续浏览其他页面。
- Android 播放带时间轴的台本时，可以开启悬浮字幕，在切换到其他应用后继续看字幕。
- Windows 桌面客户端可从开始菜单打开，并在「Ruri → 检查更新」中下载安装新版本。
- Windows 安装向导和 Linux 终端安装支持选择监听 IP、端口并检查是否可用。Windows 卸载时可保留应用数据，或明确选择清除；媒体原文件保留。
- 开启服务器授权后，可把喜欢的一段音视频选出来试听、保存，再单独播放或加入列表。珍藏片段沿用原文件，播放时需要原文件可用。
- Linux、Windows 和 Docker 发行版自带音视频工具，启动即可使用音量标准化、兼容转码和内嵌字幕。[音视频工具](USAGE.md#准备音视频工具)
- 也可用支持 WebDAV 的播放器浏览文件夹并播放原文件，使用 Ruri 的账户密码连接。文件以只读方式提供；可选择证书文件启用 HTTPS，分别设置 HTTP、HTTPS 端口，并让 HTTP 访问跳转到 HTTPS。

## 手机上听和隐私模式

- Android 客户端可搜索局域网里的 Ruri，也可手动填写地址。支持后台播放、媒体键、全屏视频和恢复队列。
- 登录已授权的服务器后，可把原文件、作品文字、封面和可用的文本字幕下载到手机。下载完成后，可在「本机媒体库」离线收听。本机下载、队列、收藏和进度由手机单独保存。
- 开启隐私模式可遮住封面、视频和作品文字，点小眼睛可临时查看 3 秒。Android 还能在外放前询问，耳机或蓝牙设备断开时暂停。
- 从账号菜单可删除一条收听记录或清空自己的记录。清除记录也会清除对应的续播位置。

## 多人使用和换机

- 内置管理员可使用网页和 WebDAV。服务器授权有效时，管理员可以为其他人创建账号。各账号共享媒体库，各自保存收藏、播放列表、偏好和收听进度。
- 管理员可调整局域网范围、为指定账号开启远程访问，也可通过 Nginx 使用 HTTPS 入口连接 HTTP 服务器。同机 Nginx 无需填写可信代理，Ruri 使用 Docker 桥接部署时也一样。
- 在登录会话中查看设备名称、客户端类型、登录 IP 和时间，撤销不用的登录。
- 管理员可备份系统数据，或导出全部作品及单部作品的资料。换机后可选择新的媒体目录恢复。暂时找不到的文件仍可保留作品资料，待文件放回后重新扫描。

- 管理员可开启或关闭游客体验；游客免密码浏览和播放演示媒体，不能保存个人内容，关闭后游客登录失效。

- 管理员可查看需要关注的问题和操作结果；排查时可在设置中开启详细诊断，完成后关闭。


## 适用范围与限制

- 发行服务器包支持 Linux/Windows x64，Docker 镜像为 Linux x86-64；没有 ARM 发行包。
- 兼容来源直接播放其提供的文件；本地文件的转码、内嵌字幕和音量标准化取决于文件格式与可用工具。
- WebDAV 只读，不提供上传、改名、删除或收听进度同步。反向代理使用独立域名根路径，不支持子目录入口。
- 浏览器不能直接读取电脑的真实主机名；会话名称用于辨认登录设备，不能证明设备身份。

## 收听统计与推荐

- 从侧边栏或账号菜单打开「收听与推荐」。在「收听统计」查看收听时长、日历、每月趋势和常听作品、声优、社团及标签，可切换最近 30 天、12 个月、年份或全部时间。这里只记录从服务器媒体库播放的内容，手机本机媒体库不计入。
- 在作品详情点击「我的评分」，选择 1～5 星；再次打开可修改或取消。评分属于自己的账号，针对整部归档作品，不同格式与播放版本共用。卡片上的「我的评分」与作品公开评分分别显示。
- 「为你推荐」提供「可能喜欢」「换换口味」「久未重听」，点作品查看详情或直接播放，点「换一批」更换推荐。删除续播记录不会删除收听统计或评分。


### 视频画质与转码限制

观看视频时，打开「播放器设置」选择「视频画质」。支持转码的视频可选分辨率和码率档位，切换后会从当前位置继续并重新缓冲；无法转码的视频只显示「原始格式」。本地来源和可读取的 kikoeru 兼容来源视频均可使用。原始格式是否能播放取决于设备。兼容播放的「自动」使用默认画质预算，不会持续随网速升降画质。

已结束的任务和运行日志最多保留 48 小时。任务结束后，可查看未完成项并重试；成功项计入汇总。记录过期后，可从作品或来源重新操作。作品资料、收藏、收听进度和字幕草稿不受影响。本次升级不保留旧任务记录；升级成功后不保留旧数据库备份。
